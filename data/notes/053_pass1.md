Here’s what I found from Ahrefs’ official developer docs and pricing pages as of November 24, 2026.

Research notes
- Product: Ahrefs — SEO/AEO data platform (backlinks, keywords, site audit, rank tracking, AI/Brand visibility) with a public REST API v3 and an official hosted MCP server. ([docs.ahrefs.com](https://docs.ahrefs.com/en/api/docs/introduction))
- Category: Data, SEO and Scraping
- auth_methods: OAuth2; API key. ([docs.ahrefs.com](https://docs.ahrefs.com/en/ahrefs-connect/docs/oauth-guide))
- primary_auth: OAuth2 (Ahrefs Connect uses OAuth 2.0 Authorization Code Flow with PKCE to act on a user’s account). ([docs.ahrefs.com](https://docs.ahrefs.com/en/ahrefs-connect/docs/oauth-guide))
- access: partner_gated (you apply to Ahrefs Connect before receiving OAuth credentials; integrations are for paid-plan users). ([docs.ahrefs.com](https://docs.ahrefs.com/en/ahrefs-connect/docs/introduction))
- api_breadth: broad (endpoints span Site Explorer, Keywords Explorer, Rank Tracker, Site Audit, SERP Overview, Batch Analysis, Brand Radar, Web Analytics, GSC Insights, Social Media, Management, etc.). ([docs.ahrefs.com](https://docs.ahrefs.com/en/api/docs/introduction))
- mcp: official (Ahrefs provides a hosted MCP server). ([docs.ahrefs.com](https://docs.ahrefs.com/en/mcp/docs/introduction))
- buildability: ready_with_caveats
  - Why: You can ship today via user-provided API keys (owners/admins can create keys), but API access is on paid plans and unit/rate limits apply. Using OAuth (preferred for multi-tenant) requires joining Ahrefs Connect and passing review. ([docs.ahrefs.com](https://docs.ahrefs.com/en/api/docs/api-keys-creation-and-management))
- blocker: paid_plan (direct API access available on paid tiers; Enterprise offers uncapped API, lower tiers have per-request caps/units). For OAuth, partner program + review are additional constraints. ([ahrefs.com](https://ahrefs.com/pricing))
- Docs URL: https://docs.ahrefs.com/en/api/docs/introduction ([docs.ahrefs.com](https://docs.ahrefs.com/en/api/docs/introduction))
- OpenAPI spec: yes (official openapi.json linked from docs). ([docs.ahrefs.com](https://docs.ahrefs.com/en/api/docs/introduction))
- Webhooks: none mentioned in the developer docs (no webhook section surfaced in API docs/pricing).
- Sandbox: no dedicated sandbox; “free test queries” are available for specific targets/keywords to avoid consuming units; an API key is still required. ([docs.ahrefs.com](https://docs.ahrefs.com/en/api/docs/free-test-queries))
- Notable limits/pricing mechanics:
  - 60 requests/min default rate limit; unit-based billing with minimum 50 units/request (varies by rows/fields). ([docs.ahrefs.com](https://docs.ahrefs.com/en/api/docs/introduction))
  - Plan comparison shows “Direct API access” and “MCP Server” across paid tiers with per-request row caps; Enterprise advertises “Uncapped API access.” ([ahrefs.com](https://ahrefs.com/pricing))
- How to get credentials:
  - API key: owners/admins create in Account settings; use Authorization: Bearer. ([docs.ahrefs.com](https://docs.ahrefs.com/en/api/docs/api-keys-creation-and-management))
  - OAuth (Ahrefs Connect): apply -> get client credentials -> implement OAuth2 PKCE -> approval process before going live. ([docs.ahrefs.com](https://docs.ahrefs.com/en/ahrefs-connect/docs/introduction))

Concise integration assessment for Composio
- Best near-term path: API key flow (user pastes a workspace API key), covering most READ endpoints across the suite; mark “paid plan required” and default 60 RPM + units. ([docs.ahrefs.com](https://docs.ahrefs.com/en/api/docs/introduction))
- Longer-term: Ahrefs Connect (OAuth2) for multi-tenant user-consent linking; requires program acceptance and review. ([docs.ahrefs.com](https://docs.ahrefs.com/en/ahrefs-connect/docs/introduction))
- MCP: Official hosted MCP server on Lite+ works out-of-the-box for agent tools, but Ahrefs notes it’s not a general-purpose programmatic API; use REST API for programmatic integrations. ([docs.ahrefs.com](https://docs.ahrefs.com/en/mcp/docs/introduction))
