LiveAgent — Integration research notes

Product: LiveAgent (Support and Helpdesk)
One‑liner: Omnichannel helpdesk with ticketing, live chat, call center, knowledge base, automations, and an API. ([liveagent.com](https://www.liveagent.com/pricing/))

Auth model
- auth_methods: API key (REST API); OAuth2 or Bearer token only for the built‑in MCP server. ([support.liveagent.com](https://support.liveagent.com/741982-API-key?utm_source=openai))
- primary_auth: API key (header apikey). ([support.liveagent.com](https://support.liveagent.com/741982-API-key?utm_source=openai))

Access to credentials
- access: self_serve_trial (30‑day free trial, no credit card; API keys available on all plans with per‑plan key limits). ([liveagent.com](https://www.liveagent.com/pricing/))

API surface
- api_breadth: broad (tickets, agents, chats, contacts/companies, departments, phones, files, tags, SLAs, etc.; v3 and v4 references). ([support.liveagent.com](https://support.liveagent.com/docs/api/v3/?utm_source=openai))

MCP
- mcp: official (LiveAgent exposes a built‑in MCP server for AI tools; supports OAuth 2.1 or bearer token). ([support.liveagent.com](https://support.liveagent.com/647358-MCP-Integration-for-agents?utm_source=openai))

Buildability for an agent toolkit
- buildability: ready_with_caveats
- blocker: paid_plan
- Rationale: API keys are self‑serve in trial and on paid plans; no app review required. Caveats: production use requires a paid plan after the trial; per‑plan API‑key limits; documented API rate limits. ([liveagent.com](https://www.liveagent.com/pricing/))

Key details
- Docs URL: https://support.liveagent.com/docs/api/v4/ (OAS 3.1) | v3 also available. ([support.liveagent.com](https://support.liveagent.com/docs/api/v4/?utm_source=openai))
- OpenAPI spec: Yes (v4 page states “OAS 3.1”). ([support.liveagent.com](https://support.liveagent.com/docs/api/v4/?utm_source=openai))
- Webhooks: Yes via automation rules “HTTP request” action (postbacks to your URL); not a separate first‑class webhook object. ([support.liveagent.com](https://support.liveagent.com/679034-Notification-postback-calls-to-external-applications-scripts?utm_source=openai))
- Sandbox: No dedicated sandbox; docs recommend using a free Trial account for testing. ([support.liveagent.com](https://support.liveagent.com/567924-Documentation?r=1&utm_source=openai))
- Rate limits: “API requests are limited to 180 per minute per API key.” Additional request/connection limits apply. ([support.liveagent.com](https://support.liveagent.com/217359-Request-rate-limits?utm_source=openai))

What it would look like in Composio
- Primary flow: User connects by pasting their LiveAgent API v3/v4 key; Composio stores it per-tenant and sends it in the apikey header to the tenant’s subdomain (https://{account}.ladesk.com/api/v3 or v4).
- Optional: For users on Business/Enterprise, Composio could also support LiveAgent’s official MCP server as an alternative channel (OAuth 2.1 or bearer token), but the REST API alone is sufficient for an agent toolkit today. ([support.liveagent.com](https://support.liveagent.com/docs/api/v4/?utm_source=openai))

Notes
- API versions: v1 (legacy) and v3/v4 (current); v3/v4 keys managed in-agent under Configuration > System > API. ([faq.liveagent.com](https://faq.liveagent.com/916372-API-v1-vs-API-v3-in-LiveAgent-Key-Differences-Authentication-and-Resolving-ApiKey-Errors?utm_source=openai))
- Data export/listing constraints: ticket listing capped (e.g., v3 /tickets max 10,000 per filtered call) introduced in 5.51+. ([support.liveagent.com](https://support.liveagent.com/170916-Limitation-of-API-to-retrieve-tickets-since-version-551?utm_source=openai))
- Plan nuances: API accessible on all plans; per‑plan API key count limits may affect multi‑system integrations. MCP server for external AI tools requires Business/Enterprise. ([liveagent.com](https://www.liveagent.com/pricing/?autm_content=blog_emails))
