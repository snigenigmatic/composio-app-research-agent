Here’s what I found on systeme.io as a potential Composio integration.

- Product description: All‑in‑one marketing platform (funnels, email, automations, courses, products, affiliates) used by solopreneurs and SMBs. ([systeme.io](https://systeme.io/features?utm_source=openai))
- Docs URL: https://developer.systeme.io/reference/api ([developer.systeme.io](https://developer.systeme.io/reference/api))

Auth
- auth_methods: API key (X-API-Key header) ([developer.systeme.io](https://developer.systeme.io/reference/api))
- primary_auth: API key ([developer.systeme.io](https://developer.systeme.io/reference/api))

Access
- access: self_serve_free — keys are generated in-account from Settings → MCP & API keys; docs don’t note plan restrictions for API keys, and MCP keys are “included in all plans.” ([help.systeme.io](https://help.systeme.io/article/2323-how-to-use-systeme-io-public-api))

API surface
- api_breadth: broad — endpoints for contacts/tags/custom fields; newsletters/campaigns and email stats; funnels/page editor (with noted limits); price plans/coupons; courses/modules/lectures; communities; automation rules; subscriptions; webhooks; digital/physical products; offers/sales settings; calendar bookings; SMS templates. ([help.systeme.io](https://help.systeme.io/article/2323-how-to-use-systeme-io-public-api))
- Rate limits: documented via X-RateLimit-* headers; 429 with Retry-After on exceed. ([developer.systeme.io](https://developer.systeme.io/reference/api))
- OpenAPI spec: none published in the official docs (developer portal provides prose/MD and an llms.txt index; no OpenAPI file referenced). ([developer.systeme.io](https://developer.systeme.io/reference/api))
- Webhooks: yes — create from Settings, choose events like Contact created/Opt-in/New sale/Sale canceled; includes logs and automatic retries. ([help.systeme.io](https://help.systeme.io/article/2930-how-to-use-systeme-ios-webhook-service))
- Sandbox: none documented; integrations use your live account keys (no separate sandbox environment mentioned in docs). ([help.systeme.io](https://help.systeme.io/article/2323-how-to-use-systeme-io-public-api))

MCP (Model Context Protocol)
- mcp: official — systeme.io ships an official MCP server and keys; connection guides for ChatGPT/Claude; “included in all plans.” ([systeme.io](https://systeme.io/mcp?utm_source=openai))

Buildability for Composio
- buildability: ready_with_caveats — the public REST API and webhooks are documented and self‑serve; caveats: no OAuth2 (API key copy/paste), and rate limits apply. ([developer.systeme.io](https://developer.systeme.io/reference/api))
- blocker: none
