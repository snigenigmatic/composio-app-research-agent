WooCommerce — Research notes (Ecommerce)

Product description
- Open‑source ecommerce plugin for WordPress with a comprehensive REST API for store management.

Docs URL
- REST API docs: https://developer.woocommerce.com/docs/apis/rest-api/ ([developer.woocommerce.com](https://developer.woocommerce.com/docs/apis/rest-api/?utm_source=openai))

Auth model
- auth_methods: API key; Basic; HMAC/signature (OAuth 1.0a over HTTP) ([developer.woocommerce.com](https://developer.woocommerce.com/docs/apis/rest-api/authentication))
- primary_auth: API key (consumer key/secret, typically via HTTP Basic over HTTPS) ([developer.woocommerce.com](https://developer.woocommerce.com/docs/apis/rest-api/authentication))

Access gating
- access: self_serve_free — admins generate keys in each WooCommerce store; no paid tier required for core REST API. ([developer.woocommerce.com](https://developer.woocommerce.com/docs/apis/rest-api/authentication))

API surface
- api_breadth: broad — endpoints cover orders, products, customers, coupons, taxes, shipping, settings, webhooks, reports, etc. ([developer.woocommerce.com](https://developer.woocommerce.com/docs/apis/rest-api/v3/))

MCP (Model Context Protocol)
- mcp: official — WooCommerce AI exposes an official MCP server for stores (remote via WordPress.com OAuth, plus optional direct API‑key transport). ([woocommerce.com](https://woocommerce.com/document/woocommerce-ai/mcp-server/))

Buildability for an agent toolkit
- buildability: ready — self‑serve creds per store + stable REST API; MCP server available for agent workflows.
- blocker: none

Other implementation details
- OpenAPI spec: none published for the core WooCommerce store REST API (docs are human‑readable MD/MDX). Separate Woo Marketplace Billing API publishes an OpenAPI spec (not the store REST API). ([developer.woocommerce.com](https://developer.woocommerce.com/docs/woo-marketplace/billing-api-saas?utm_source=openai))
- Webhooks: yes — first‑class webhooks configurable in admin; many event topics. ([woocommerce.com](https://woocommerce.com/document/webhooks/))
- Sandbox: no official sandbox for the store REST API; test against a dev/staging WooCommerce site. (Marketplace Billing API has a sandbox domain, but that’s a different API.) ([developer.woocommerce.com](https://developer.woocommerce.com/docs/woo-marketplace/billing-api-saas?utm_source=openai))

Concise evidence
- primary_auth | https://developer.woocommerce.com/docs/apis/rest-api/authentication | “You may use HTTP Basic Auth by providing the REST API Consumer Key as the username and the REST API Consumer Secret as the password.” ([developer.woocommerce.com](https://developer.woocommerce.com/docs/apis/rest-api/authentication))
- access | https://developer.woocommerce.com/docs/apis/rest-api/authentication | “To create or manage keys for a specific WordPress user, go to WooCommerce > Settings > Advanced > REST API.” ([developer.woocommerce.com](https://developer.woocommerce.com/docs/apis/rest-api/authentication))
- api_breadth | https://developer.woocommerce.com/docs/apis/rest-api/v3/ | “Use `/wp-json/wc/v3/`… The … API allows you to create, view, update, and delete… [Coupons, Customers, Orders, Products, … Settings, Shipping, Webhooks, Reports].” ([developer.woocommerce.com](https://developer.woocommerce.com/docs/apis/rest-api/v3/))
- webhooks | https://woocommerce.com/document/webhooks/ | “WooCommerce can trigger webhook notifications each time you add, edit, or delete orders, products, coupons, or customers…” ([woocommerce.com](https://woocommerce.com/document/webhooks/))
- mcp | https://woocommerce.com/document/woocommerce-ai/mcp-server/ | “Connect an external Model Context Protocol (MCP) client to your store’s WooCommerce AI server… The WordPress.com URL includes your store identifier… [and] Optional: direct API‑key connection… accepts the X‑MCP‑API‑Key header in consumer_key:consumer_secret format.” ([woocommerce.com](https://woocommerce.com/document/woocommerce-ai/mcp-server/))

Notes and caveats for Composio
- Each merchant’s base URL and keys differ; app must store per‑store base_url + key/secret.
- Some hosts strip Authorization headers; query‑string auth is supported as fallback. ([developer.woocommerce.com](https://developer.woocommerce.com/docs/apis/rest-api/authentication))
- If an agent flow is desired, the official Woo MCP server provides a higher‑level, permission‑scoped tool interface and OAuth via WordPress.com. ([woocommerce.com](https://woocommerce.com/document/woocommerce-ai/mcp-server/))
