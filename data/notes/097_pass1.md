Here’s what I found about Higgsfield (higgsfield.ai)

- Product description: Generative media platform providing image/video models and tools via a self‑serve REST API, an official MCP server for agents, and a CLI. ([docs.higgsfield.ai](https://docs.higgsfield.ai/docs))

Auth model and access
- auth_methods: API key
- primary_auth: API key
  - Evidence: API requests use the Authorization header “Key <api-key>” and the docs also show “Key ${HF_API_KEY_ID}:${HF_API_KEY_SECRET}.” The Quick Start clarifies you paste the complete copied key. ([open.higgsfield.ai](https://open.higgsfield.ai/quick-start))
- How to get credentials: Create an API key in the Open Higgsfield console after sign‑in (free signup shows “Sign up with a business email and get $15”). ([open.higgsfield.ai](https://open.higgsfield.ai/auth/sign-in?redirect_url=/api-keys))
- access: self_serve_trial (self‑serve keys; initial free credits; then prepaid balance/pay‑as‑you‑go) ([open.higgsfield.ai](https://open.higgsfield.ai/auth/sign-in?redirect_url=/api-keys))

API surface
- Endpoint shape: submit to model-specific paths, then poll status or receive a webhook; also file upload via signed URL. Core operations include submit, status, cancel, and generate-upload-url. ([docs.higgsfield.ai](https://docs.higgsfield.ai/docs))
- Base URL: https://api.higgsfield.ai. ([open.higgsfield.ai](https://open.higgsfield.ai/models/soul-id/api-reference?utm_source=openai))
- API breadth: moderate (many model operations over a small set of core resources: generation requests, status/cancel, files). ([docs.higgsfield.ai](https://docs.higgsfield.ai/docs))

MCP and CLI
- mcp: official (vendor‑hosted MCP server) — official setup page and server URL mcp.higgsfield.ai/mcp. ([higgsfield.ai](https://higgsfield.ai/creator-hub/help-center/getting-started/official-higgsfield-platforms?fp_sid=ko-is-higgsfield-safe--src&fpr=lax-8e2251&utm_source=openai))
- CLI: officially documented; “npm i -g @higgsfield/cli”; “higgsfield auth login” opens browser sign‑in. ([higgsfield.ai](https://higgsfield.ai/CLI))

Buildability for an agent toolkit
- buildability: ready (public docs; self‑serve keys; official MCP; straightforward REST)
- blocker: none
- Notable caveats:
  - Docs show two key formats (“Key <api-key>” vs “Key id:secret”); Quick Start instructs to paste the complete key as a single value. Treat as a single API key token in integrations. ([open.higgsfield.ai](https://open.higgsfield.ai/quick-start))
  - No separate sandbox environment is advertised; API ToS say sandbox/GPU compute would be covered by separate terms “if and when launched.” Budget for real spend or trial credits. ([open.higgsfield.ai](https://open.higgsfield.ai/terms-of-service?utm_source=openai))

Docs, specs, webhooks, sandbox
- Docs URL: https://docs.higgsfield.ai (index points to llms.txt; model pages live under Open Higgsfield console). ([docs.higgsfield.ai](https://docs.higgsfield.ai/docs))
- OpenAPI spec: yes (a “shared OpenAPI file” exists, but is described as supplementary; model catalog authoritative in console/docs). ([open.higgsfield.ai](https://open.higgsfield.ai/quick-start))
- Webhooks: yes (polling or receive a webhook when processing finishes). ([docs.higgsfield.ai](https://docs.higgsfield.ai/docs))
- Sandbox: none (no public sandbox; ToS notes sandbox offerings “if and when launched”). ([open.higgsfield.ai](https://open.higgsfield.ai/terms-of-service?utm_source=openai))
