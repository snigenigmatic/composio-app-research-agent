Here’s what I found about Bright Data.

- Product description: Web data platform providing web scraping APIs (Web Unlocker, SERP, Web Scraper), a cloud Browser API, proxy networks, and ready-made datasets. ([docs.brightdata.com](https://docs.brightdata.com/introduction))
- Docs URL: https://docs.brightdata.com (landing page “Bright Data documentation”). ([docs.brightdata.com](https://docs.brightdata.com/introduction))

Auth model
- auth_methods: API key; Basic (native proxy username:password) — “Authenticate… using 1 of 2 methods: API Access with an API key or Native Access with proxy username and password.” ([docs.brightdata.com](https://docs.brightdata.com/api-reference/authentication))
- primary_auth: API key (Bearer) — “Include the API Key in the Authorization header… Format: Authorization: Bearer YOUR_API_KEY.” ([docs.brightdata.com](https://docs.brightdata.com/api-reference/rest-api/unlocker/unlock-website))

Access (how to get credentials)
- access: self_serve_free — “Get 5,000 free credits per month, no credit card, across Web Unlocker API, SERP API, Web Scraper API, Scraper Studio and Browser API.” Also: “An API key… We create a default key for you upon account creation automatically.” ([docs.brightdata.com](https://docs.brightdata.com/general/account/billing-and-pricing/free-tier))

API surface
- api_breadth: broad (multiple products and dozens of endpoints across Unlocker /request, Datasets v3 (/scrape, /trigger, /progress), SERP, Browser API, Scraper Studio, etc.). Example refs show Unlocker /request and Datasets v3 /progress. ([docs.brightdata.com](https://docs.brightdata.com/api-reference/rest-api/unlocker/unlock-website))

MCP server
- mcp: official — “Use the Bright Data MCP server to give AI agents real-time access to public web data… 5,000 free requests per month.” ([docs.brightdata.com](https://docs.brightdata.com/products/mcp-server/overview))

Buildability for an agent toolkit (Composio)
- buildability: ready — self-serve API keys, comprehensive docs, official MCP server; nothing material blocking initial integration.
- blocker: none

Other implementation notes
- OpenAPI spec: Yes (vendor-published OpenAPI 3 specs for Web Unlocker and SERP on Bright Data’s site/blog). ([brightdata.com](https://brightdata.com/blog/ai/bright-data-openapi-specs?utm_source=openai))
- Webhooks: Yes (central “Webhook notifications” reference). ([docs.brightdata.com](https://docs.brightdata.com/general/webhook_notifications))
- Sandbox: No separate sandbox environment; production APIs with free-tier credits and optional “Limited trial” restrictions until verification. ([docs.brightdata.com](https://docs.brightdata.com/general/account/billing-and-pricing/free-tier))
