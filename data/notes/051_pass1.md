Here are my research notes on DataForSEO

- Product: DataForSEO — pay‑as‑you‑go SEO data APIs (SERP, keywords, backlinks, on‑page, business data)
- Category: Data, SEO and Scraping
- Primary auth: Basic
- Auth methods: Basic
- Access: self_serve_trial
- API breadth: broad
- MCP: official
- Buildability: ready
- Blocker: none
- Docs URL: https://docs.dataforseo.com/v3/
- OpenAPI spec: yes (official repo)
- Webhooks: yes (pingbacks/postbacks)
- Sandbox: yes

Why these values
- Authentication is HTTP Basic with an API login and a generated API password (distinct from the dashboard password). Credentials are obtained self‑serve from the account’s API Access page after free signup. Evidence below supports Basic auth and self‑serve credential acquisition.
- Access is self_serve_trial because every new account gets an unlimited trial period, a free sandbox, and $1 trial credit; production usage is pay‑as‑you‑go with a $50 minimum top‑up, no plan gating.
- API breadth is broad: their v3 docs span SERP, Keywords Data, OnPage, Backlinks, Business Data, DataForSEO Labs, Domain Analytics, Content Analysis, Merchant, App Data, Databases, and Appendix.
- MCP server: an official Model Context Protocol server is published in the verified DataForSEO GitHub org.
- Webhooks exist via “pingbacks” and “postbacks,” plus a webhook resend endpoint.
- Buildability is ready: credentials are self‑serve; docs, OpenAPI specs, SDKs, and an API Playground/Sandbox exist; no partner program or app review needed.

Additional notes
- Pricing model: pay‑as‑you‑go; every registered account can call all endpoints; free trial/sandbox; minimum top‑up $50. ([dataforseo.com](https://dataforseo.com/faq))
- Rate limits: FAQ notes a default limit of 2,000 API calls per minute; SERP overview mentions up to 10,000 calls/min for certain flows, with higher limits by request. ([dataforseo.com](https://dataforseo.com/faq))
- Postbacks/pingbacks are first‑class, and there’s an Appendix webhook_resend endpoint. ([docs.dataforseo.com](https://docs.dataforseo.com/v3/appendix/webhook_resend/?utm_source=openai))
- Official clients exist (TypeScript, Python, C#, Java), and an in‑dashboard API Playground is available. ([github.com](https://github.com/dataforseo/TypeScriptClient?utm_source=openai))
