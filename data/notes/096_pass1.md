Devin — Integration research notes (as of November 24, 2026)

- What it is: Devin is Cognition’s AI software engineer platform (cloud, desktop, CLI) with a public REST API and an official MCP server to manage sessions, knowledge, playbooks, schedules, etc. ([docs.devin.ai](https://docs.devin.ai/api-reference/overview.md))
- Docs URL: https://docs.devin.ai (API overview and MCP pages) ([docs.devin.ai](https://docs.devin.ai/api-reference/overview.md))

Auth model
- auth_methods: Bearer/PAT token (service-user API key with cog_ prefix; optional Personal Access Tokens)
- primary_auth: Bearer/PAT token
- Notes: v3 uses “principal + token.” Service-user keys and PATs begin with cog_. Legacy apk_ keys are deprecated. PATs are in closed beta and unavailable for SSO/Enterprise. ([docs.devin.ai](https://docs.devin.ai/es/api-reference/authentication?utm_source=openai))

Access to credentials
- access: paid_plan
- Rationale: Self-serve plans exist; Pro explicitly lists MCP integration. Free plan lists usage/Review/DeepWiki but not API/MCP. Teams/Enterprise flows show “Settings > Devin API” to create service users. Evidence does not show API/MCP on Free. ([docs.devin.ai](https://docs.devin.ai/admin/billing/self-serve.md))
- How to get creds: In-app “Settings > Devin API > Service users” (org or enterprise scope) to provision key (cog_), then call v3 endpoints. ([docs.devin.ai](https://docs.devin.ai/api-reference/getting-started/teams-quickstart.md))

API surface
- Base URLs: https://api.devin.ai/v3/organizations/* and /v3/enterprise/*; service-user credentials recommended. ([docs.devin.ai](https://docs.devin.ai/api-reference/overview.md))
- api_breadth: broad (sessions, knowledge, playbooks, schedules, integrations, analytics, audit logs, users, IP access lists, etc.). ([docs.devin.ai](https://docs.devin.ai/api-reference/overview.md))
- Notable: Session attribution via create_as_user_id; RBAC/permissions per endpoint; v1/v2 legacy still available during migration. ([docs.devin.ai](https://docs.devin.ai/api-reference/overview.md))

MCP
- mcp: official
- Official server: https://mcp.devin.ai/mcp
- Auth: HTTP Authorization: Bearer <API_KEY>; enterprise tokens may require X-Org-Id header. ([docs.devin.ai](https://docs.devin.ai/work-with-devin/devin-mcp))
- Tools: repository docs (DeepWiki), session/playbook/knowledge/schedule management, integrations, automations, review, code scans, org utilities. ([docs.devin.ai](https://docs.devin.ai/work-with-devin/devin-mcp))

Buildability for an agent toolkit
- buildability: ready_with_caveats
- Why: Public, well-documented REST API and an official MCP server; credentials are self-serve on paid plans. Caveats: paid plan gating; PATs still beta; some enterprise-only controls. ([docs.devin.ai](https://docs.devin.ai/api-reference/overview.md))
- blocker: paid_plan

Other implementation notes
- OpenAPI spec: not found in docs. (No Swagger/OpenAPI mention surfaced.)
- Webhooks: not found in docs.
- Sandbox: no separate API sandbox environment mentioned (docs describe enterprise dedicated deployments, but not a sandbox API). ([docs.devin.ai](https://docs.devin.ai/api-reference/getting-started/enterprise-quickstart.md))
