Here’s what I found on Zendesk as an integration target for agents.

Auth model
- auth_methods: OAuth2; API tokens with Basic auth are being removed; basic email+password deprecated
- primary_auth: OAuth2

Access
- access: app_review
  - Why: You can self-create an OAuth client for a single Zendesk account in Admin Center, but any multi-tenant/public integration that connects to multiple Zendesk customers must use a Zendesk-issued global OAuth client, which you must request and have approved via the Marketplace developer portal.

API surface
- api_breadth: broad

MCP status
- mcp: official
  - Zendesk now ships an official MCP client inside Zendesk (connects to external MCP servers) and also exposes a Zendesk MCP server that external AI agents can connect to (in EAP/Bridge).

Buildability for a Composio toolkit
- buildability: ready_with_caveats
- blocker: app_review
  - You can build and test right away with a trial/sponsored dev account and a local OAuth client. To ship a multi-tenant toolkit customers can authorize, you’ll need Zendesk to convert your client to a global OAuth client (Marketplace request/approval). Also note plan-based API rate limits and ongoing auth deprecations (API tokens → OAuth).

One‑line product description
- Zendesk is a customer support platform (tickets, help center, messaging, voice, CRM) with extensive REST APIs for automations, apps, and integrations.

Docs URL
- Developer docs home: https://developer.zendesk.com/api-reference/

OpenAPI spec, Webhooks, Sandbox
- OpenAPI spec: Yes (Ticketing and Help Center provide downloadable OAS files).
- Webhooks: Yes (first‑party Webhooks product and API).
- Sandbox: Yes (plan‑dependent sandboxes; sponsored developer accounts for partners; trials for development).

Key implementation notes
- OAuth flows: Authorization Code and Client Credentials are supported; scopes are enforced; PKCE is required for public clients; refresh tokens supported.
- Global OAuth: Required for any public/multi‑account app; you request conversion of a local client to a global one via the Marketplace portal; Zendesk may restrict allowed scopes on the global client.
- API tokens EOL: Support API tokens are being removed in phases and stop working April 30, 2027. Plan your OAuth migration accordingly.
