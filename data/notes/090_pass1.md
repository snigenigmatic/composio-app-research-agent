Here’s what I found on PitchBook’s API and MCP surface area.

- Product description: Private- and public-markets data provider; offers a REST API, scheduled data feeds, and an official MCP “Premium Connector” to bring PitchBook data into AI assistants and internal tools.
- Docs URL: https://pitchbook.com/help/PitchBook-api

Auth model
- auth_methods: API key; Bearer/PAT token
- primary_auth: API key
- Notes: PitchBook’s help docs say the Direct Data team provisions either an API key or an auth token. For the MCP Premium Connector, authentication is via SSO for licensed users.

Access and gating
- access: contact_sales
- Why: The API is a separate offering that requires a standalone contract and you start by contacting the Direct Data team.
- Pricing note: Direct Data (API or feed) is priced separately from the platform license (by volume/refresh/specs).

API surface
- api_breadth: broad (entities include companies, deals, investors, funds, LPs, people, service providers; plus relational/financial endpoints)
- Protocol/format: REST, JSON
- OpenAPI spec: not publicly provided (none found)
- Webhooks: not documented (none found)
- Sandbox: not documented; PitchBook mentions testing endpoints inside the platform’s Plugins & Apps section, but no public sandbox is described.

MCP
- mcp: official (PitchBook Data MCP / Premium Connector)
- MCP auth: SSO for licensed PitchBook users (via partner UIs like Claude, ChatGPT, Copilot)
- Availability: “available to customers upon request” (Premium/“Data MCP”)
- Notes: PitchBook positions MCP alongside Direct Feed and API as distribution options.

Buildability for an agent toolkit (Composio)
- buildability: needs_outreach
- blocker: enterprise_sales
- Rationale: No self-serve developer credentials; API/MCP access is tied to paid, licensed customers and coordinated through PitchBook’s Direct Data team (and SSO for MCP). Technically feasible, but requires commercial agreement and customer licensing.

Concise research notes
- Primary endpoints/base: api.pitchbook.com (REST/JSON). Help docs indicate a variety of relational endpoints; product page lists core entity types.
- Auth distribution: API key or static auth token, issued after engagement with Direct Data; MCP uses SSO tied to customer entitlements.
- Plans/licensing: API is a separate, contract-based product priced independently of the platform; MCP Premium requires a PitchBook seat/unlimited/trial license and SSO.
