Here are the integration research notes for Salesforce.

- Product: Salesforce — enterprise CRM and application platform (Sales, Service, Marketing, Platform)
- Category: CRM and Sales
- Docs URL: https://developer.salesforce.com/docs/platform/api-rest/guide/intro-rest.html ([developer.salesforce.com](https://developer.salesforce.com/docs/platform/api-rest/guide/intro-rest.html?utm_source=openai))

Auth
- auth_methods: OAuth2; JWT/service account. For external apps you create a Connected App and use OAuth 2.0; JWT bearer and client-credentials flows are available. ([help.salesforce.com](https://help.salesforce.com/s/articleView?id=xcloud.connected_app_create_api_integration.htm&language=en_US&type=5))
- primary_auth: OAuth2 (Connected App). ([help.salesforce.com](https://help.salesforce.com/s/articleView?id=xcloud.connected_app_create_api_integration.htm&language=en_US&type=5))

Access
- access: self_serve_free (anyone can get a free Developer Edition org and create a Connected App to obtain client ID/secret). Note many customer orgs require an edition with API Enabled for production use. ([developer.salesforce.com](https://developer.salesforce.com/free-trials))

API
- api_breadth: broad (multiple APIs: REST, SOAP, Bulk, Tooling, Metadata, GraphQL, Connect, Pub/Sub, etc.). ([help.salesforce.com](https://help.salesforce.com/s/articleView?id=integrate_what_is_api.htm&language=en_US&type=5&utm_source=openai))
- OpenAPI spec: Partial/optional. Salesforce provides org-tailored OpenAPI 3.x document generation for sObjects REST API as a beta/pilot feature (dev/sandbox and API-enabled orgs). ([resources.docs.salesforce.com](https://resources.docs.salesforce.com/254/latest/en-us/sfdc/pdf/salesforce_spring25_release_notes.pdf))
- Webhooks/events: Yes. Outbound Messages send SOAP to an external endpoint; Change Data Capture streams record changes in near real time. ([help.salesforce.com](https://help.salesforce.com/s/articleView?id=sf.workflow_managing_outbound_messages.htm&language=en_US&type=5))
- Sandbox: Yes (multiple sandbox types for testing; plus free Developer Edition orgs). ([help.salesforce.com](https://help.salesforce.com/s/articleView?id=000387743&language=en_US&type=1))

MCP (Model Context Protocol)
- mcp: official. Salesforce provides Hosted MCP Servers to connect AI clients (e.g., Claude, ChatGPT, Cursor) to Salesforce data and actions. ([help.salesforce.com](https://help.salesforce.com/s/articleView?id=release-notes.rn_headless360_mcp_servers.htm&language=en_US&type=5))

Buildability for an agent toolkit
- buildability: ready_with_caveats
- blocker: paid_plan
- Why: Technically straightforward with OAuth2 and rich APIs; free dev orgs enable development immediately. Caveats: customer orgs must have API access (Enterprise/Unlimited/Performance/Developer by default; Professional requires add-on; Essentials/Group not available), plus per-org admin approval/installation of your Connected App and standard Salesforce API limits. ([help.salesforce.com](https://help.salesforce.com/s/articleView?id=000005140&language=en_US&type=1))

One‑line product description
- Salesforce is a leading enterprise CRM and low-code platform with extensive APIs for data, metadata, automation, analytics, and eventing. ([help.salesforce.com](https://help.salesforce.com/s/articleView?id=integrate_what_is_api.htm&language=en_US&type=5&utm_source=openai))

Notes for Composio
- Best default flow: Create a multi-tenant Connected App and use OAuth 2.0 Authorization Code (with PKCE) for user-consent installs; optionally support JWT Bearer/server-to-server for admin-approved org-wide connections. ([help.salesforce.com](https://help.salesforce.com/s/articleView?id=xcloud.connected_app_create_api_integration.htm&language=en_US&type=5))
- Important gating: Customer org must have API Enabled per edition; Professional needs Web Services API add-on; Essentials/Group lack API. This is the primary commercial constraint even though development is free in Developer Edition. ([help.salesforce.com](https://help.salesforce.com/s/articleView?id=000005140&language=en_US&type=1))
- Useful surfaces: REST (sObjects, query, composite), Bulk API 2.0 for high volume, Tooling/Metadata for config, Pub/Sub/CDC for change streams, Outbound Messages for webhook-style pushes. ([help.salesforce.com](https://help.salesforce.com/s/articleView?id=integrate_what_is_api.htm&language=en_US&type=5&utm_source=openai))

Confidence: high for auth/access/API scope; medium for OpenAPI availability details (feature is explicitly beta/pilot and subject to change). ([resources.docs.salesforce.com](https://resources.docs.salesforce.com/254/latest/en-us/sfdc/pdf/salesforce_spring25_release_notes.pdf))
