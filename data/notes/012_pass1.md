Intercom — Research notes (Support and Helpdesk)

- Product: Intercom
- One‑liner: Customer service platform (Messenger, Inbox, Tickets, Help Center) with AI features (Fin) and a public developer platform.
- Docs URL: https://developers.intercom.com/docs

Auth
- auth_methods: OAuth2; Bearer/PAT token
- primary_auth: OAuth2
- Notes:
  - Private apps use a workspace Access Token (Bearer). Public apps use OAuth. ([developers.intercom.com](https://developers.intercom.com/docs/build-an-integration/learn-more/authentication))

Access/gating
- access: app_review
- Details:
  - Free “development workspaces” let you create apps and test APIs. ([intercom.com](https://www.intercom.com/help/en/articles/9071694-intercom-developer-faqs))
  - Public apps require OAuth and submission for review before broad install/publish. ([developers.intercom.com](https://developers.intercom.com/docs))

API surface
- api_breadth: broad
- Notes:
  - REST Admin API covers Contacts, Companies, Conversations, Tickets, Articles, Calls, Brands, WhatsApp, etc. ([developers.intercom.com](https://developers.intercom.com/docs/references/rest-api/api.intercom.io?utm_source=openai))
  - OpenAPI spec: yes (official repo and downloadable from reference). ([github.com](https://github.com/intercom/Intercom-OpenAPI?utm_source=openai))
  - Webhooks: yes (usable from paid or development workspaces). ([developers.intercom.com](https://developers.intercom.com/docs/webhooks))
  - Sandbox: yes (free development workspaces; US-only). ([developers.intercom.com](https://developers.intercom.com/docs))

MCP (Model Context Protocol)
- mcp: official
- Notes:
  - Intercom hosts an official remote MCP server (US/EU endpoints) with OAuth or Bearer auth options. ([developers.intercom.com](https://developers.intercom.com/docs/guides/mcp))

Buildability for an agent toolkit (Composio)
- buildability: ready_with_caveats
- blocker: app_review
- Rationale:
  - You can build today with self‑serve dev workspaces, PATs, OAuth, webhooks, and a published OpenAPI. Public, multi‑tenant distribution will need Intercom’s app review; some MCP Operator tools require the Fin Operator permission/add‑on. ([developers.intercom.com](https://developers.intercom.com/docs))

Additional implementation notes (quick)
- OAuth scopes and review: OAuth is required for public apps; private apps need no review. ([developers.intercom.com](https://developers.intercom.com/docs))
- OpenAPI: Official OpenAPI description published by Intercom (GitHub: intercom/Intercom-OpenAPI). ([github.com](https://github.com/intercom/Intercom-OpenAPI?utm_source=openai))
- Webhooks config is done in Developer Hub (not via API for new subscriptions). ([developers.intercom.com](https://developers.intercom.com/docs/webhooks))
