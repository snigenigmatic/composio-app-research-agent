Here’s what I found on Notion as a potential Composio toolkit.

- auth_methods: OAuth2; Bearer/PAT token (internal connection tokens and personal access tokens). ([developers.notion.com](https://developers.notion.com/guides/authorization/overview))
- primary_auth: OAuth2 (best choice for multi‑tenant apps; official OAuth flow and endpoints). ([developers.notion.com](https://developers.notion.com/guides/authorization/overview))
- access: self_serve_free (you can create internal/public integrations from the developer portal; public integrations can be authorized by any workspace; Marketplace listing is optional and applied for separately). ([developers.notion.com](https://developers.notion.com/guides/connections-and-tokens/overview))
- api_breadth: broad (REST API covers pages, databases, blocks, users, search, comments, views, data sources, file upload, webhooks, etc.). ([developers.notion.com](https://developers.notion.com/openapi.json))
- mcp: official (Notion hosts a remote MCP server). ([developers.notion.com](https://developers.notion.com/guides/mcp/get-started-with-mcp))
- buildability: ready (self‑serve credentials, comprehensive docs/OpenAPI, OAuth, and webhooks are available).
- blocker: none

Product description: All‑in‑one workspace for notes, docs, databases, projects, and team collaboration.

Docs URL: https://developers.notion.com

OpenAPI spec: Yes — JSON at developers.notion.com/openapi.json (OpenAPI 3.1). ([developers.notion.com](https://developers.notion.com/openapi.json))

Webhooks: Yes — “connection webhooks” deliver real‑time events for page/database changes. ([developers.notion.com](https://developers.notion.com/reference/webhooks))

Sandbox: No separate sandbox environment documented; you build/test against a Notion workspace (free workspaces supported). ([notion.com](https://www.notion.com/help/create-integrations-with-the-notion-api))

Additional implementation notes
- Base URL and headers: HTTPS to https://api.notion.com with Authorization: Bearer and a Notion‑Version header. ([developers.notion.com](https://developers.notion.com/reference/intro))
- OAuth: Authorization Code flow; authorize at /v1/oauth/authorize and exchange code at /v1/oauth/token (Basic auth). ([developers.notion.com](https://developers.notion.com/guides/authorization/overview))
