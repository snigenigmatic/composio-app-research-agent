DealCloud — Integration research notes (CRM and Sales)

- Product summary: DealCloud (by Intapp) is a deal and relationship management platform for financial services, with per-tenant REST APIs for data, schema, files, user management, backups, and event streams. ([investors.intapp.com](https://investors.intapp.com/static-files/0ee3d729-5d42-4ef7-8fe0-0bfbd926509c?utm_source=openai))
- Docs URL: https://api.docs.dealcloud.com (API overview: /docs) ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/?utm_source=openai))

Auth
- auth_methods: OAuth2 (client credentials); API key (used as the client_secret for OAuth token requests) ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/token?utm_source=openai))
- primary_auth: OAuth2 (client credentials) — access token used as Bearer; tokens expire after 15 minutes. ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/token?utm_source=openai))

Access
- access: paid_plan — credentials are created within a customer’s DealCloud site by an admin; there is no public developer signup. Users must be in a group with “API” capability to enable/copy their API key; some features (e.g., Publications) require account manager enablement. ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/apikeys?utm_source=openai))

API surface
- api_breadth: broad — APIs cover Authentication, Schema, Data (CRUD), Files, User Management, Backups, History, Merge, Template Reports, Relationship Intelligence, and Publications (event stream). ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/token))
- OpenAPI/Swagger: yes — each site exposes Swagger UI and an OpenAPI spec at https://{host}/swagger/current. ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs?utm_source=openai))
- Webhooks: not documented; instead, real-time events via Publications API (poll/stream topics; 9‑day retention; per-tenant). ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/publications?utm_source=openai))
- Sandbox: yes (vendor-operated preview/non‑production sandboxes for DealCloud) — “non-production (or preview) sandbox… to safely test… APIs,” and status site lists “DealCloud … Sandbox Operational.” ([intapp.com](https://www.intapp.com/dealcloud/enterprise-offering/?utm_source=openai))
- Rate limits: e.g., Data/Schema 5 rps; token 300/min; Publications 1000 rps. ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/limits))

MCP
- mcp: official — DealCloud provides an official MCP server (DealCloud with Celeste license) for AI agents; includes OAuth sign-in and tool surface. ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/releases?utm_source=openai))

Buildability for a Composio toolkit
- buildability: ready_with_caveats
- blocker: paid_plan
- Notes: Technically straightforward (OAuth2 client credentials, per-tenant base URL + scopes). Caveats: customers must provision creds inside their tenant; some eventing (Publications) needs account manager enablement; moderate per-endpoint rate limits; tokens expire in 15 minutes (must re-request). ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/token?utm_source=openai))

Quick capability map (selected)
- Data APIs: create, retrieve, update, delete across objects (entryLists such as deals, contacts, companies). ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/data?utm_source=openai))
- Schema APIs: inspect objects/fields, metadata, currencies, time zones; read-only for structure. ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/schema?utm_source=openai))
- Files APIs: upload/download/export. ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/token))
- User Management: CRUD users, groups, invite users. ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/management?utm_source=openai))
- Publications: real-time events via topics; stateful session; 9‑day retention. ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/publications?utm_source=openai))

What a developer needs to obtain credentials
- Inside a DealCloud tenant: an admin enables API capability on the user’s group; the user then enables and copies their API key from Profile. Use client_id + client_secret (API key) to request OAuth2 tokens with required scopes (e.g., data, user_management, publish). ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/apikeys?utm_source=openai))

If anything is unclear
- The docs do not state public developer sign-up or a free developer tier; everything is provisioned per customer tenant via admin permissions. Publications explicitly require account manager enablement. Accordingly, I classified access as paid_plan with caveats rather than self_serve_free. ([api.docs.dealcloud.com](https://api.docs.dealcloud.com/docs/apikeys?utm_source=openai))
