iPayX — integration research notes (Finance/Fintech)

- Product description: Forensic FX audit engine that compares a transaction’s bank rate to the mid‑market benchmark to expose hidden spreads; offered as a REST API and an official MCP server. ([ipayx.ai](https://www.ipayx.ai/docs/api?utm_source=openai))

- Auth methods: Bearer/PAT token; webhooks use HMAC-SHA256 signatures. Primary_auth: Bearer/PAT token. ([ipayx.ai](https://www.ipayx.ai/docs/api?utm_source=openai))

- Access: self_serve_free (docs show you can generate API keys in the dashboard; MCP docs describe a free tier), but marketing/pricing copy implies API access is part of paid plans — treat as free dev keys with likely paid usage for full REST features. ([ipayx.ai](https://www.ipayx.ai/docs/mcp-server?utm_source=openai))

- API breadth: narrow (docs list 3 endpoints: audit, rates, audit/document). ([ipayx.ai](https://www.ipayx.ai/docs/api?utm_source=openai))

- MCP: official (vendor-hosted MCP server and docs). ([ipayx.ai](https://www.ipayx.ai/docs/mcp-server?utm_source=openai))

- Buildability: ready_with_caveats (keys appear self‑serve; API is narrow; pricing page suggests API features may require a paid plan; docs site is somewhat thin/JS‑rendered). Blocker: paid_plan. ([ipayx.ai](https://www.ipayx.ai/?utm_source=openai))

- Docs URL: https://www.ipayx.ai/docs/api (developer entry pages also at /developers and MCP docs at /docs/mcp-server). ([ipayx.ai](https://www.ipayx.ai/docs/api?utm_source=openai))

- OpenAPI spec: Yes (OpenAPI 3.1 referenced in docs). ([ipayx.ai](https://www.ipayx.ai/docs/api?utm_source=openai))

- Webhooks: Yes — signed HMAC-SHA256; at least audit.completed event. ([ipayx.ai](https://www.ipayx.ai/docs/api?utm_source=openai))

- Sandbox: Yes — “Test Sandbox” is advertised; separate sandbox reference page exists. ([ipayx.ai](https://www.ipayx.ai/?utm_source=openai))

What the API/MCP look like (from docs)
- REST base and endpoints: Docs show a REST v1 “FX Audit API” with endpoints including /audit, /rates, and /audit/document; bearer tokens start ipx_live_. ([ipayx.ai](https://www.ipayx.ai/docs/api?utm_source=openai))
- Webhook verification: HMAC-SHA256 via x-ipayx-signature. ([ipayx.ai](https://www.ipayx.ai/docs/api?utm_source=openai))
- MCP server: Production endpoint published with instructions and free/paid tool tiers; “How to get a key: Open your iPayX dashboard → API keys.” ([ipayx.ai](https://www.ipayx.ai/docs/mcp-server?utm_source=openai))
