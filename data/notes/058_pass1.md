Why this classification
- The official materials show Sherlock as an installable CLI (pipx/pip/Docker) with command‑line usage; there’s no hosted API or OAuth/keyed developer platform. ([sherlockproject.xyz](https://sherlockproject.xyz/installation))
- The org does publish a separate “api” repo, but it’s a self‑hosted Django REST Framework server you run locally (e.g., runserver on 127.0.0.1) — not a public SaaS API. ([github.com](https://github.com/sherlock-project/api?utm_source=openai))
