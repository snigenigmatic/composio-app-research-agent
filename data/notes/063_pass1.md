Here are integration research notes for Netlify

- Product: Netlify — a cloud platform to build, deploy, and run modern web apps and sites.
- Docs URL: https://docs.netlify.com/api-and-cli-guides/api-guides/get-started-with-api/ ([docs.netlify.com](https://docs.netlify.com/api-and-cli-guides/api-guides/get-started-with-api/?utm_source=openai))

Auth model
- auth_methods: OAuth2; Bearer/PAT token
- primary_auth: OAuth2 (for public integrations/agents acting on a user’s account)
  - Netlify uses OAuth2 for authentication; the API also supports personal access tokens (PATs) used as Bearer tokens. ([docs.netlify.com](https://docs.netlify.com/api-and-cli-guides/api-guides/get-started-with-api/?utm_source=openai))
  - Developers can self-register OAuth apps and generate PATs in User settings; registering an app provides a client ID and client secret. ([docs.netlify.com](https://docs.netlify.com/manage/accounts-and-billing/user-settings/?utm_source=openai))

Access and gating
- access: self_serve_free (free signup yields credentials via PATs and allows registering an OAuth app) ([docs.netlify.com](https://docs.netlify.com/manage/accounts-and-billing/user-settings/?utm_source=openai))
- Notes on gating:
  - Some webhook capabilities (organization webhooks) are Enterprise-only. ([netlify.com](https://www.netlify.com/changelog/?utm_source=openai))
  - API rate limits apply (e.g., 500 requests/min typical; deploys up to 3/min and 100/day; higher limits by request). ([docs.netlify.com](https://docs.netlify.com/api-and-cli-guides/api-guides/get-started-with-api/?utm_source=openai))

API surface
- Base URL: https://api.netlify.com/api/v1/ (HTTPS only). ([docs.netlify.com](https://docs.netlify.com/api-and-cli-guides/api-guides/get-started-with-api/?utm_source=openai))
- OpenAPI/Swagger: official spec published in the netlify/open-api repo; security definition is OAuth2; basePath /api/v1; includes resources like sites, deploys, hooks, etc. ([github.com](https://github.com/netlify/open-api?utm_source=openai))
- api_breadth: broad (dozens of resources across sites, deploys, builds, hooks, members, DNS, etc., per OpenAPI spec). ([github.com](https://github.com/netlify/open-api/blob/master/swagger.yml?utm_source=openai))

Webhooks
- Incoming: Build hooks (HTTP POST to unique URL to trigger builds/deploys). ([docs.netlify.com](https://docs.netlify.com/build/configure-builds/build-hooks/?utm_source=openai))
- Outgoing: Deploy notifications with signed headers. ([docs.netlify.com](https://docs.netlify.com/deploy/deploy-notifications/?utm_source=openai))
- Organization-level webhooks: available but require Enterprise plan. ([docs.netlify.com](https://docs.netlify.com/manage/accounts-and-billing/organization-webhooks/?utm_source=openai))

MCP
- mcp: official (Netlify ships an official MCP server to let agents use the Netlify API/CLI). ([netlify.com](https://www.netlify.com/press/netlify-launches-official-mcp-server-setting-the-standard-for-agent-native-development/?utm_source=openai))

Buildability for an agent toolkit
- buildability: ready
- blocker: none
  - Rationale: OAuth2 and PATs are self-serve; comprehensive REST API with OpenAPI spec; webhook support. Caveats: rate limits and some enterprise-only webhook features. ([docs.netlify.com](https://docs.netlify.com/api-and-cli-guides/api-guides/get-started-with-api/?utm_source=openai))

Other implementation notes
- Rate limits: typical 500 req/min; deploys 3/min and 100/day; headers expose remaining quota. ([docs.netlify.com](https://docs.netlify.com/api-and-cli-guides/api-guides/get-started-with-api/?utm_source=openai))
- SDKs/clients: Go and JS clients referenced from the OpenAPI repo. ([github.com](https://github.com/netlify/open-api/blob/master/swagger.yml?utm_source=openai))
- Registration endpoints:
  - OAuth authorize endpoint: https://app.netlify.com/authorize (per docs). ([docs.netlify.com](https://docs.netlify.com/api-and-cli-guides/api-guides/get-started-with-api/?utm_source=openai))

Extras requested
- OpenAPI spec available: Yes (netlify/open-api). ([github.com](https://github.com/netlify/open-api?utm_source=openai))
- Webhooks available: Yes (build hooks, deploy notifications; org webhooks on Enterprise). ([docs.netlify.com](https://docs.netlify.com/build/configure-builds/build-hooks/?utm_source=openai))
- Sandbox: No separate sandbox documented; use free accounts/projects for development and testing.
