Here are the integration notes for Gorgias.

- Product: Gorgias
- One‑line description: Ecommerce‑focused helpdesk and AI platform (built for Shopify) that unifies email, chat, social, SMS, and voice support.
- Category: Support and Helpdesk
- Docs URL: https://developers.gorgias.com/

Auth
- auth_methods: OAuth2; Basic
- primary_auth: OAuth2
- Notes: Public apps must use OAuth2; private apps use HTTP Basic with email:API key.

Access
- access: self_serve_trial
- Notes: Any Gorgias account (free 7‑day trial or paid) can generate API credentials; public apps require review to be listed.

API surface
- api_breadth: broad
- Examples: tickets, customers, macros, rules (CRUD and search/filters). ([developers.gorgias.com](https://developers.gorgias.com/reference/list-tickets?utm_source=openai))

MCP availability
- mcp: official
- Notes: Official Gorgias MCP for Claude/ChatGPT and generic HTTP MCP clients; available on all Helpdesk plans. ([docs.gorgias.com](https://docs.gorgias.com/en-US/connect-your-ai-assistant-to-the-gorgias-mcp-6310546))

Buildability for an agent toolkit (Composio)
- buildability: ready_with_caveats
- blocker: app_review
- Rationale: You can build and test immediately (trial + sandbox) and ship OAuth2, but broad multi‑tenant distribution/listing in the Gorgias App Store requires app review; customers need an active Gorgias workspace.

Other implementation details
- OpenAPI spec: none officially published (docs are human‑readable; Postman collection is provided from the UI).
- Webhooks: yes (via HTTP Integrations that trigger on ticket events; agent‑click “HTTP hook” macros also exist). ([helpcenter.gorgias.com](https://helpcenter.gorgias.com/en-US/connect-external-apps-to-gorgias-and-create-sidebar-widgets-81822?utm_source=openai))
- Sandbox: yes (convert a trial to a Sandbox by emailing the dev team after creating a draft app). ([developers.gorgias.com](https://developers.gorgias.com/docs/overview?utm_source=openai))
