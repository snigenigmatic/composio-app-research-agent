Here are the integration research notes for Monday.com.

- App: monday.com
- Category: Productivity and Project Management
- Product one-liner: Work OS for managing projects, CRM, dev and service work, with a GraphQL API and an official hosted MCP server for AI agents. ([developer.monday.com](https://developer.monday.com/api-reference/?utm_source=openai))
- Docs URL: https://developer.monday.com/api-reference/
- auth_methods: OAuth2; Bearer/PAT token (personal API tokens) ([developer.monday.com](https://developer.monday.com/api-reference/docs/build-on-monday-with-ai))
- primary_auth: OAuth2 (best for multi‑tenant/public distribution) ([developer.monday.com](https://developer.monday.com/api-reference/docs/build-on-monday-with-ai))
- access: app_review — Self‑serve dev creds are available (free developer account/personal token). To reach many customer accounts via a public OAuth app and marketplace distribution, an app review/approval is required; shareable links are allowed but unreviewed apps are flagged. ([developer.monday.com](https://developer.monday.com/api-reference/docs/authentication))
- api_breadth: broad (GraphQL covering boards, items, columns, users/teams, docs, updates, CRM Emails & Activities, app/marketplace APIs, etc.). ([developer.monday.com](https://developer.monday.com/api-reference/reference/about-the-api-reference?utm_source=openai))
- mcp: official — monday.com operates a hosted MCP server and documents MCP tools/flows. ([developer.monday.com](https://developer.monday.com/api-reference/docs/integrate-with-monday-mcp))
- buildability: ready_with_caveats — You can ship now using OAuth2 or personal tokens; public multi‑tenant distribution will be constrained by marketplace review and per‑plan API limits. ([developer.monday.com](https://developer.monday.com/apps/docs/install-and-share-your-apps))
- blocker: app_review
- OpenAPI spec: No official OpenAPI; API is GraphQL with downloadable/introspectable schema (get_schema). ([developer.monday.com](https://developer.monday.com/api-reference/docs/introduction-to-graphql?utm_source=openai))
- Webhooks: Yes (board webhooks and app lifecycle webhooks). ([developer.monday.com](https://developer.monday.com/api-reference/reference/webhooks))
- Sandbox: Yes — free developer account for building/testing; also higher dev limits noted. ([developer.monday.com](https://developer.monday.com/api-reference/docs/authentication))

Notes and caveats:
- Rate limits are per account and vary by plan; API remains a “free feature across all plans,” with daily call caps (e.g., Free 200; Standard/Basic 1,000; Pro/Trial 10,000; Enterprise 25,000). MCP tool calls consume from the same quota. Consider this when designing agent loops. ([developer.monday.com](https://developer.monday.com/api-reference/docs/rate-limits))

Evidence (2–5):

- OAuth & endpoints | https://developer.monday.com/api-reference/docs/build-on-monday-with-ai | “The Platform MCP uses OAuth 2.0 Authorization Code Grant… MCP client redirects to https://auth.monday.com/oauth2/authorize.” ([developer.monday.com](https://developer.monday.com/api-reference/docs/build-on-monday-with-ai))

- MCP (official hosted server) | https://developer.monday.com/api-reference/docs/integrate-with-monday-mcp | “Connect your MCP client to the monday.com hosted MCP server — choose API token, OAuth, or dynamic client registration… Server URL: https://mcp.monday.com/mcp.” ([developer.monday.com](https://developer.monday.com/api-reference/docs/integrate-with-monday-mcp))
- Webhooks | https://developer.monday.com/api-reference/reference/webhooks | “Webhooks… provide real‑time updates… subscribe to events on your boards and get notified by an HTTP or HTTPS post request.” ([developer.monday.com](https://developer.monday.com/api-reference/reference/webhooks))
