Here are the integration research notes for Google Ads.

- Product: Google Ads
- Category: Marketing, Ads, Email and Social
- One‑line description: Google’s advertising platform and API for programmatic management, reporting, and optimization of Google Ads accounts and campaigns. ([developers.google.com](https://developers.google.com/google-ads/api/docs/get-started/introduction?hl=en&utm_source=openai))
- Docs URL: developers.google.com/google-ads/api ([developers.google.com](https://developers.google.com/google-ads/api?utm_source=openai))

- auth_methods: OAuth2; JWT/service account
  - Notes: Google Ads API supports both OAuth 2.0 user flows and service accounts. As of 2026-09-09, developer tokens were sunset and API access is now determined by the Google Cloud project used to obtain OAuth credentials. ([developers.google.com](https://developers.google.com/google-ads/api/rest/auth?hl=en))
- primary_auth: OAuth2
  - Rationale: A multi‑tenant toolkit acting on customers’ accounts should use user-consent OAuth 2.0; service accounts are supported when the service account is granted access to the customer’s Ads account. ([developers.google.com](https://developers.google.com/google-ads/api/docs/oauth/overview))

- access: app_review
  - Why: You can self‑serve enable the API and apply for Explorer access (automated). Basic and Standard access require application; brand verification is required for Basic and Standard, and Standard typically involves manual review. ([developers.google.com](https://developers.google.com/ads/blog/posts/2026/09/new-onboarding-experience-for-google-ads-api))

- api_breadth: broad
  - Evidence: v26 reference spans core reporting/mutation plus Campaigns, Ad Groups & Ads; Accounts, Assets & Performance Max; Conversions, Audiences & Planning, etc. ([developers.google.com](https://developers.google.com/google-ads/api/reference/rpc/v26/overview?utm_source=openai))

- mcp: official
  - Evidence: Google publishes an official Google Ads MCP server and developer guide. ([developers.google.com](https://developers.google.com/google-ads/api/docs/developer-toolkit/mcp-server))

- buildability: ready_with_caveats
  - Why: Public, well‑documented API with OAuth2 and service-account support; official MCP server available. Caveats: API access levels (Explorer/Basic/Standard) with brand verification and reviews; production calls require approved access level; rate limits apply. ([developers.google.com](https://developers.google.com/ads/blog/posts/2026/09/new-onboarding-experience-for-google-ads-api))

- blocker: app_review

- OpenAPI spec: No official OpenAPI spec; Google provides a per‑version Google API Discovery document (machine‑readable JSON) instead. ([developers.google.com](https://developers.google.com/google-ads/api/rest/design/overview))

- Webhooks: Yes (narrow). Google Ads provides webhooks for Lead Form extensions; general account events are not exposed via generic webhooks. ([developers.google.com](https://developers.google.com/google-ads/webhook/docs/overview))

- Sandbox: Yes. Test manager and test client accounts act as a free sandbox; test data may be auto‑deleted. ([developers.google.com](https://developers.google.com/google-ads/api/docs/best-practices/test-accounts))

- Pricing/plan notes: “The Google Ads API is free to use” (Explorer, Basic, Standard); RMF non‑compliance fees can apply to Standard. ([developers.google.com](https://developers.google.com/google-ads/api/docs/productionize/access-levels))

Concise research notes for auth and access details
- Authentication headers: Bearer access tokens in Authorization header; login-customer-id when acting via a manager account. ([developers.google.com](https://developers.google.com/google-ads/api/rest/auth?hl=en))
- Service accounts: Directly supported; set up a service account and key to obtain OAuth 2.0 access tokens. ([developers.google.com](https://developers.google.com/google-ads/api/rest/auth?hl=en))
- Developer token status: Sunset on September 9, 2026; access levels now tied to your Google Cloud project; developer-token header is optional and ignored. ([developers.google.com](https://developers.google.com/google-ads/api/docs/api-policy/developer-token))
- Access levels: Apply from Google Cloud Console; Basic and Standard require brand verification; production calls from unapproved projects return CLOUD_PROJECT_NOT_APPROVED_FOR_PRODUCTION. ([developers.google.com](https://developers.google.com/ads/blog/posts/2026/09/new-onboarding-experience-for-google-ads-api))
- Discovery doc: A per‑version discovery document is published at googleads.googleapis.com/$discovery/rest?version=<API_VERSION>. ([developers.google.com](https://developers.google.com/google-ads/api/rest/design/overview))

Notes for Composio implementers
- Primary auth to support: OAuth2 user-consent flow (for multi‑tenant) and service accounts (if customers can add the service account user to their Ads account). Include login-customer-id header when acting via manager accounts. ([developers.google.com](https://developers.google.com/google-ads/api/rest/auth?hl=en))
- Access path: Enable API on a Google Cloud project → apply for Explorer (automated) → Basic (automated after brand verification) or Standard (manual review). Production calls require approved access level; otherwise expect CLOUD_PROJECT_NOT_APPROVED_FOR_PRODUCTION. ([developers.google.com](https://developers.google.com/ads/blog/posts/2026/09/new-onboarding-experience-for-google-ads-api))
- API shape: gRPC-first with REST bindings; rich surface across management and reporting; query via GAQL; discovery document available (no OpenAPI). ([developers.google.com](https://developers.google.com/google-ads/api/rest/overview?hl=en&utm_source=openai))
- Webhooks: Only for lead form assets; for other event ingestion rely on polling/reporting or offline conversions uploads. ([developers.google.com](https://developers.google.com/google-ads/webhook/docs/overview))
- Testing: Use test manager/client accounts as a sandbox during development. ([developers.google.com](https://developers.google.com/google-ads/api/docs/best-practices/test-accounts))
