QuickBooks (Intuit) — Developer research notes

- Product description: QuickBooks Online is Intuit’s small‑business accounting platform with REST and GraphQL APIs for accounting data and related features. ([static.developer.intuit.com](https://static.developer.intuit.com/output_html/qbo/docs/learn/explore-the-quickbooks-online-api.html?utm_source=openai))

Auth model
- auth_methods: OAuth2 (authorization code; access + refresh tokens) ([developer.intuit.com](https://developer.intuit.com/app/developer/qbo/docs/develop/authentication-and-authorization/oauth-2.0?utm%3Cem%3Ecampaign=integrations-break-year-2&utm%3Cem%3Esource=stoa-agency&utm_source=openai))
- primary_auth: OAuth2

Access gating
- access: app_review — development creds and sandbox are self‑serve, but moving an app into production requires Intuit’s review/approval (app assessment/questionnaire) even for private apps. ([static.developer.intuit.com](https://static.developer.intuit.com/output_html/qbo/docs/legal-agreements/intuit-terms-of-service-for-intuit-developer-services.html))

API surface
- api_breadth: broad — APIs “let apps utilize most customer‑facing features in QuickBooks Online,” with many entities and reports across REST and GraphQL. Some “Premium APIs” (Projects, Custom Fields, Sales Tax, Payroll/Workforce, Dimensions) are available only to App Partner Program tiers. ([static.developer.intuit.com](https://static.developer.intuit.com/output_html/qbo/docs/learn/explore-the-quickbooks-online-api.html?utm_source=openai))

MCP
- mcp: official — Intuit publishes an open-source “QuickBooks Online MCP Server” exposing QBO features as MCP tools. ([github.com](https://github.com/intuit/quickbooks-online-mcp-server/blob/main/README.md))

Buildability for an agent toolkit
- buildability: ready_with_caveats — You can build today with self‑serve dev creds and sandbox; production use requires passing Intuit’s assessment, and some useful APIs are partner‑gated. ([static.developer.intuit.com](https://static.developer.intuit.com/output_html/qbo/docs/develop/sandboxes/manage-your-sandboxes.html))
- blocker: app_review

Key implementation details
- Getting credentials: Create an app in the Intuit Developer portal to obtain Client ID/Secret; separate Development (sandbox) and Production keys. Production keys appear after the App Assessment Questionnaire is approved. ([developer.intuit.com](https://developer.intuit.com/app/developer/qbo/docs/get-started/get-client-id-and-client-secret?utm_source=openai))
- Sandbox: A QBO sandbox company is created automatically with your developer profile; up to 10 sandboxes; sandbox base URL https://sandbox-quickbooks.api.intuit.com/v3. ([static.developer.intuit.com](https://static.developer.intuit.com/output_html/qbo/docs/develop/sandboxes/manage-your-sandboxes.html))
- Webhooks: Supported for many entities; require OAuth2‑connected companies; deliver CloudEvents‑style payloads; verify with HMAC-SHA256 and an app verifier token. ([static.developer.intuit.com](https://static.developer.intuit.com/output_html/qbo/docs/develop/webhooks/configure-webhooks.html))
- OpenAPI spec: No official OpenAPI/OAS published in the docs; Intuit provides API Explorer and maintains Postman collections for QBO and Payments. ([static.developer.intuit.com](https://static.developer.intuit.com/output_html/qbo/docs/release-notes/general-release-notes.html?utm_source=openai))
- Docs URL (primary): QuickBooks Online developer docs and “Get started.” ([developer.intuit.com](https://developer.intuit.com/app/developer/qbo/docs/?utm_source=openai))

Evidence (2–5 items)
- OAuth2 auth | Set up OAuth 2.0 | “Your app should send the authorization code … back to the Intuit OAuth 2.0 server to exchange it for access and refresh tokens.” ([developer.intuit.com](https://developer.intuit.com/app/developer/qbo/docs/develop/authentication-and-authorization/oauth-2.0?utm%3Cem%3Ecampaign=integrations-break-year-2&utm%3Cem%3Esource=stoa-agency&utm_source=openai))
- Production gating | Intuit Developer Terms | “Before your Developer Application can be publicly distributed and in other instances as determined solely by Intuit you may be required to submit a self‑assessment questionnaire… Upon Intuit’s review and approval, your Application will enter production and become accessible to Users.” ([static.developer.intuit.com](https://static.developer.intuit.com/output_html/qbo/docs/legal-agreements/intuit-terms-of-service-for-intuit-developer-services.html))
- Sandbox availability | Manage your sandboxes | “When you create your developer profile, you automatically get a sandbox company.” ([static.developer.intuit.com](https://static.developer.intuit.com/output_html/qbo/docs/develop/sandboxes/manage-your-sandboxes.html))
- Premium/partner‑gated APIs | Get started | “Silver, Gold, and Platinum partners have access to Premium APIs including the Projects API, Custom Fields API, Sales Tax API, and Payroll Compensation API.” ([developer.intuit.com](https://developer.intuit.com/app/developer/qbo/docs/?utm_source=openai))
- MCP server (official) | Intuit GitHub | “QuickBooks Online MCP Server… provides complete QuickBooks Online API integration for Claude Code and other MCP‑compatible clients.” ([github.com](https://github.com/intuit/quickbooks-online-mcp-server/blob/main/README.md))

Notes and uncertainties
- OpenAPI: I did not find an official OAS/Swagger file in Intuit’s docs; they reference API Explorer and Postman collections instead. If you need OAS for codegen, we may need to generate it from the Postman collections or rely on SDKs. ([static.developer.intuit.com](https://static.developer.intuit.com/output_html/qbo/docs/release-notes/general-release-notes.html?utm_source=openai))
- Some newer/graphQL “Premium APIs” require App Partner Program enrollment (Silver+). This constrains breadth unless the partner tier is obtained. ([help.developer.intuit.com](https://help.developer.intuit.com/s/question/0D5TR00001Z93zt0AB/quickbooks-api-for-updating-client-records?utm_source=openai))
