Klaviyo — Integration research notes

- Product: Klaviyo is a customer marketing platform for email, SMS, push, and reviews; its APIs cover profiles, events, lists/segments, campaigns/flows, reporting, catalogs, coupons, and more. ([developers.klaviyo.com](https://developers.klaviyo.com/en/docs/get_started))
- Docs URL: https://developers.klaviyo.com (latest docs indicate v2026-10-15 as of November 24, 2026). ([developers.klaviyo.com](https://developers.klaviyo.com/en/docs/authenticate_))
- Auth methods: OAuth2; API key (private key for server-side, public key aka site/company ID for client-side); Basic (only for OAuth token/revoke endpoints). ([developers.klaviyo.com](https://developers.klaviyo.com/en/docs/authenticate_))
- Primary auth (for a multi-tenant agent): OAuth2. Klaviyo recommends OAuth for tech partners and marketplace apps; access tokens are then used as Bearer to call APIs. ([developers.klaviyo.com](https://developers.klaviyo.com/en/docs/authenticate_))
- Access: self_serve_free. Any account can create API keys and OAuth apps; new test accounts start on the free plan; free plan is advertised and self-serve. ([developers.klaviyo.com](https://developers.klaviyo.com/en/docs/get_started))
- API breadth: broad (dozens of resources across Accounts, Profiles, Events, Metrics/Reporting, Lists/Segments, Campaigns, Flows, Templates, Catalogs, Coupons, Tags, Reviews, Subscriptions, Data Privacy, etc.). ([developers.klaviyo.com](https://developers.klaviyo.com/en/reference?utm_source=openai))
- MCP: official. Klaviyo publishes an official MCP server (remote-hosted and local) to let AI clients operate on account data with OAuth. ([developers.klaviyo.com](https://developers.klaviyo.com/en/docs/klaviyo_mcp_server))
- Buildability: ready_with_caveats. Core APIs and OAuth are self-serve; however, public App Marketplace listing requires app review, and the Webhooks API is limited to Advanced KDP customers or app partners. ([developers.klaviyo.com](https://developers.klaviyo.com/en/docs/set_up_oauth))
- Blocker: app_review (for marketplace listing; not needed to run an unlisted OAuth app). ([developers.klaviyo.com](https://developers.klaviyo.com/en/docs/set_up_oauth))

Other implementation notes
- OpenAPI spec: Yes (official, versioned; OpenAPI 3.0.2). ([raw.githubusercontent.com](https://raw.githubusercontent.com/klaviyo/openapi/2026-10-15/openapi/stable.json))
- Webhooks: Yes. Flow webhooks (UI action) and System webhooks; Webhooks API management is restricted to Advanced KDP customers and Klaviyo app partners. ([developers.klaviyo.com](https://developers.klaviyo.com/en/docs/working_with_system_webhooks))
- Sandbox: No separate environment, but you can create a designated “test account” (linked to the same login); new test accounts start on the free plan. ([developers.klaviyo.com](https://developers.klaviyo.com/en/docs/create_a_test_account))
