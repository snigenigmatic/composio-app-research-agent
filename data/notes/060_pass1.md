Here’s what I found on Clay (clay.com)

Product: Clay — a GTM data platform for finding, enriching and activating leads, with an AI agent (“Claygent”), searches over a proprietary people/companies graph, workflows/functions, Audiences, and an official MCP server to let external agents run Clay tools.

Auth model
- auth_methods: OAuth2; API key. Public REST API calls use a Clay API key in the clay-api-key header; MCP uses OAuth2 with Dynamic Client Registration. ([developers.clay.com](https://developers.clay.com/public-api/authentication))
- primary_auth: OAuth2 (via MCP) for multi-tenant agent toolkits; REST Public API supports API keys tied to a user/workspace. ([university.clay.com](https://university.clay.com/docs/connect-to-clay-mcp))

Access to credentials
- access: self_serve_free
  - Anyone can generate an API key in-app or via CLI; no platform review noted. ([developers.clay.com](https://developers.clay.com/quickstart))
  - “The developer platform is available across all Clay plans, including free, trial, and Legacy plans.” ([university.clay.com](https://university.clay.com/docs/clay-api-cli))
  - MCP registration is open (“no Clay-side approval step”). ([university.clay.com](https://university.clay.com/docs/connect-to-clay-mcp))

API surface
- Base: api.clay.com/public/v0 (example: GET /public/v0/me). ([developers.clay.com](https://developers.clay.com/public-api/authentication))
- Primitives covered in docs: Searches, Routines (Clay-managed + custom functions; Workflows alpha), Audiences, Signals; Tables is Enterprise-only. ([developers.clay.com](https://developers.clay.com/))
- api_breadth: moderate (core objects and execution primitives; not full CRUD over every table; Tables API is read-only and Enterprise-only). ([university.clay.com](https://university.clay.com/docs/clay-api-cli))

MCP / agent support
- mcp: official. Clay exposes an official MCP server with OAuth2 DCR; external platforms can register and call tools. ([university.clay.com](https://university.clay.com/docs/connect-to-clay-mcp))

Buildability for an agent toolkit
- buildability: ready_with_caveats
  - Why ready: Self-serve API keys, official MCP OAuth, OpenAPI spec, webhooks. ([developers.clay.com](https://developers.clay.com/quickstart))
  - Caveats:
    - Default API rate limit 300 requests/min/workspace; some endpoints may have additional limits. ([developers.clay.com](https://developers.clay.com/public-api/rate-limits))
    - Searches have per-request, per-search, and per-period caps that vary by plan. ([developers.clay.com](https://developers.clay.com/searches))
    - Tables API requires Enterprise (“Tables are Enterprise only”). ([developers.clay.com](https://developers.clay.com/))
    - Pricing page lists “HTTP API integrations” under Growth and “Clay API access” under Enterprise; dev docs say the developer platform works on all plans, so advanced surfaces (e.g., Tables) likely drive the plan notes. Treat plan entitlements carefully. ([clay.com](https://www.clay.com/pricing?version=published))
- blocker: none

Docs and capabilities
- Docs URL: https://developers.clay.com/ (Public API, reference, OpenAPI, rate limits, webhooks) and Clay University for product-facing setup. ([developers.clay.com](https://developers.clay.com/))
- OpenAPI spec: yes (developers.clay.com/openapi.json). ([developers.clay.com](https://developers.clay.com/openapi.json))
- Webhooks: yes (signed deliveries when a routine run finishes; verify X-Clay-Signature). ([developers.clay.com](https://developers.clay.com/public-api/webhooks))
- Sandbox: no dedicated sandbox; free plan and a 14‑day trial exist for testing. ([clay.com](https://www.clay.com/pricing?version=published))

Recommended integration path for Composio
- Primary path: OAuth2 to Clay’s official MCP server (Dynamic Client Registration) to let users connect their Clay workspace without sharing personal API keys; expose tools/calls that run Searches and Functions. Use REST Public API+API key only where needed (e.g., reading run results, credits). ([university.clay.com](https://university.clay.com/docs/connect-to-clay-mcp))
