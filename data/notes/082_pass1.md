Here’s what I found on Plaid as an integration target.

- Product description: Plaid is a financial data connectivity platform that lets apps link users’ bank accounts and access account, transaction, identity, payments/transfer and other data via API. ([plaid.com](https://plaid.com/docs/api/))
- Primary docs: https://plaid.com/docs/api/ ([plaid.com](https://plaid.com/docs/api/))

Auth model
- auth_methods: API key (client_id + secret in headers or body). ([plaid.com](https://plaid.com/docs/api/))
- primary_auth: API key. ([plaid.com](https://plaid.com/docs/api/))

Access (how a developer gets credentials)
- access: app_review — keys are self‑serve from the Dashboard, but full Production/OAuth use requires requesting Production access and completing registration (incl. a security questionnaire for US/CA). ([plaid.com](https://plaid.com/docs/api/))

API surface
- api_breadth: broad — many product families (Auth, Transactions, Identity, Assets, Liabilities, Investments, Transfers, Payment Initiation EU, etc.). ([plaid.com](https://plaid.com/docs/api/))

MCP server
- mcp: official — Plaid provides an MCP server as part of its AI coding toolkit. ([github.com](https://github.com/plaid/ai-coding-toolkit?utm_source=openai))

Buildability for an agent toolkit
- buildability: ready_with_caveats — docs + SDKs + OpenAPI and Sandbox are robust; production usage (esp. OAuth institutions) gated by production access review and likely paid plans. ([plaid.com](https://plaid.com/docs/sandbox/))
- blocker: app_review (production/OAuth registration). ([plaid.com](https://plaid.com/docs/link/oauth/?utm_source=openai))

Other implementation signals
- OpenAPI spec: yes (official plaid-openapi repo). ([github.com](https://github.com/plaid/plaid-openapi))
- Webhooks: yes (central reference + product webhooks; configured via webhook parameter on /link/token/create). ([plaid.com](https://plaid.com/docs/api/webhooks/))
- Sandbox: yes — free, fully featured; Sandbox API keys available in Dashboard. ([plaid.com](https://plaid.com/docs/sandbox/))
- Environments: sandbox.plaid.com and production.plaid.com. ([plaid.com](https://plaid.com/docs/api/))
