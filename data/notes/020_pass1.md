Here are the research notes for Gladly (Support and Helpdesk)

- Product: Gladly — a customer service/helpdesk platform organized around customer conversations (voice, email, SMS, chat, social) with REST APIs, webhooks, and AI/MCP features. ([gladly.ai](https://www.gladly.ai/?utm_source=openai))
- Docs URL: https://developer.gladly.com/rest/ ([developer.gladly.com](https://developer.gladly.com/rest/index.html))

Auth model
- auth_methods: Basic; HMAC/signature (for Lookup requests from Gladly to your service); None (for Public Answers API); OAuth2 (used by Gladly’s MCP for Claude and by outbound MCP connections) ([developer.gladly.com](https://developer.gladly.com/rest/index.html))
- primary_auth: Basic (email as username, API token as password, over HTTPS). ([developer.gladly.com](https://developer.gladly.com/rest/index.html))

Access and gating
- access: contact_sales (you must have a Gladly org to create API tokens; public site funnels new users to “Request a demo”). ([help.gladly.com](https://help.gladly.com/docs/generate-api-tokens-and-create-webhooks/?utm_source=openai))

API surface
- api_breadth: broad (agents, customers, conversations, communications, tasks, inboxes, reports, webhooks, etc.). ([developer.gladly.com](https://developer.gladly.com/rest/index.html))

MCP
- mcp: official (Gladly operates an MCP server for Claude; it also connects out to your external MCP servers). ([help.gladly.com](https://help.gladly.com/docs/set-up-the-gladly-mcp-for-claude?utm_source=openai))

Buildability for Composio
- buildability: needs_outreach (you need a live Gladly tenant; no self-serve dev org). Blocker: enterprise_sales. ([help.gladly.com](https://help.gladly.com/docs/generate-api-tokens-and-create-webhooks/?utm_source=openai))

Other implementation notes
- OpenAPI spec: Yes (“Download OpenAPI specification” via ReDoc). ([developer.gladly.com](https://developer.gladly.com/rest/index.html))
- Webhooks: Yes (create/list/update/delete; many events; limit 20 per org; supports Basic or header-token verification). ([developer.gladly.com](https://developer.gladly.com/rest/index.html))
- Sandbox: Yes (separate environment at https://{organization}.gladly.qa). ([developer.gladly.com](https://developer.gladly.com/rest/index.html))
