Here are integration research notes for Harvest (harvestapp.com)

- Product: Time tracking, invoicing, expenses, and lightweight project tracking for client work. 
- Docs URL: https://help.getharvest.com/api-v2/ ([help.getharvest.com](https://help.getharvest.com/api-v2/))

Auth model
- auth_methods: OAuth2; Bearer/PAT token (personal access token). The v2 API “requires an access token” with two options: Personal Access Token or “a full OAuth2 Authentication flow,” and requests also include Harvest-Account-Id. ([help.getharvest.com](https://help.getharvest.com/api-v2/authentication-api/authentication/authentication/))
- primary_auth: OAuth2 (best for multi-tenant integrations so users can connect their own accounts). ([help.getharvest.com](https://help.getharvest.com/api-v2/authentication-api/authentication/authentication/))

Access to credentials
- access: self_serve_free. All accounts, including free and trial, have API access; OAuth apps and PATs are created self-serve in Harvest ID. ([support.getharvest.com](https://support.getharvest.com/hc/en-us/articles/360048180732-The-Harvest-API?utm_source=openai))

API surface
- base URL: https://api.harvestapp.com/v2 (examples across docs use this host). ([help.getharvest.com](https://help.getharvest.com/api-v2/introduction/overview/general/?utm_source=openai))
- api_breadth: broad. V2 covers Clients, Company, Invoices, Estimates, Expenses, Tasks, Timesheets, Projects, Roles, Users, multiple Reports, Paid Time Off, Approvals, Notifications, Reimbursements, Imports, and more (plus Forecast). ([help.getharvest.com](https://help.getharvest.com/api-v2/))
- notable requirements: Include Authorization: Bearer, Harvest-Account-Id, and a User-Agent header or requests will fail. ([help.getharvest.com](https://help.getharvest.com/api-v2/authentication-api/authentication/authentication/))
- rate limits: “100 requests per 15 seconds” for general API; “100 requests per 15 minutes” for Reports; 429 with Retry-After on exceed. ([help.getharvest.com](https://help.getharvest.com/api-v2/introduction/overview/general/?utm_source=openai))

MCP server
- mcp: official. Harvest publishes an MCP (Model Context Protocol) server for AI assistants at https://api.harvestapp.com/mcp with setup instructions for Claude, Cursor, and ChatGPT. ([support.getharvest.com](https://support.getharvest.com/hc/en-us/articles/46293697226381-Harvest-MCP))

Buildability
- buildability: ready. Self-serve creds, robust REST API, and an official MCP endpoint. ([help.getharvest.com](https://help.getharvest.com/api-v2/authentication-api/authentication/authentication/))
- blocker: none.

Other implementation notes
- OpenAPI spec: none found (no official OpenAPI/Swagger published); an official Postman collection is linked instead. ([help.getharvest.com](https://help.getharvest.com/api-v2/introduction/overview/postman-collection/?utm_source=openai))
- Webhooks: none documented in v2; instead Harvest provides a pull-based Notifications API (beta) to list events like timesheet_submitted and invoice_paid. Confidence: medium. ([help.getharvest.com](https://help.getharvest.com/api-v2/notifications-api/notifications/notifications/))
- Sandbox: no separate sandbox. API access is available on trial and the permanent Free plan; use your own account. ([support.getharvest.com](https://support.getharvest.com/hc/en-us/articles/360048180732-The-Harvest-API?utm_source=openai))
- Pricing/plans context (for testing/agent rollout): Harvest offers a Free plan (1 seat, 2 projects) and paid plans; API access is included on free and trial. ([getharvest.com](https://www.getharvest.com//pricing?utm_source=openai))
