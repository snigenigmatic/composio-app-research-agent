One-line product description:
- Unified B2B contact/company intelligence API that aggregates 30+ vendors for prospecting, enrichment (emails, phones), job-change checks, company reveal, and email verification. ([waterfall.io](https://www.waterfall.io/))

Docs URL:
- https://docs.waterfall.io/v1/introduction ([docs.waterfall.io](https://docs.waterfall.io/v1/introduction))

OpenAPI spec available:
- Yes (docs list “Open API Specification”). ([docs.waterfall.io](https://docs.waterfall.io/v1/openapi-spec))

Webhooks:
- Yes (signed webhooks with Ed25519; JWKS endpoint documented). ([docs.waterfall.io](https://docs.waterfall.io/v1/webhook-verification))

Sandbox:
- No public sandbox/test environment mentioned in the docs (not found).

API surface (indicative):
- Prospector, Search Contact, Search Company (preview), Contact Enrichment, Phone Enrichment, Company Enrichment, Company Reveal, Company Titles (preview), Job Change, Email Verification, Account Reporting, API Key Management. ([docs.waterfall.io](https://docs.waterfall.io/v1/introduction))

Notes on access and auth:
- API calls authenticated via x-api-key; keys issued after contacting the team; sub-key management exists for accounts with a master key. ([docs.waterfall.io](https://docs.waterfall.io/v1/authentication))

Why buildability = needs_outreach:
- There is a solid, well-documented REST API, but developers must talk to sales to obtain a key (no self-serve signup flow exposed), so Composio would need to coordinate access for customers or work with Waterfall on a partner flow first. ([docs.waterfall.io](https://docs.waterfall.io/v1/quickstart))
