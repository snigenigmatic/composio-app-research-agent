Here are the research notes for Pumble.

- Product: Pumble — team chat and collaboration app by CAKE.com for channels, DMs, calls, and integrations.
- Category: Communications and Messaging
- Docs URL (dev platform): https://cake-com.github.io/pumble-node-sdk/ (official SDK + platform docs). ([cake-com.github.io](https://cake-com.github.io/pumble-node-sdk/?utm_source=openai))

Auth and access
- auth_methods: OAuth2; API key (API Keys add-on); Bot token; HMAC/signature for verifying incoming requests; Incoming webhook URL token. (OAuth2 flow and tokens for apps, API key for the “API” add-on; app key + token headers on API calls.) ([cake-com.github.io](https://cake-com.github.io/pumble-node-sdk/authorization.html))
- primary_auth: OAuth2 (App install + user consent yields accessToken and botToken; requests use x-app-token + token). ([cake-com.github.io](https://cake-com.github.io/pumble-node-sdk/authorization.html))
- access: app_review — you can self-serve create/install apps and get working credentials; publishing a Public app to the CAKE.com Marketplace requires review. ([cake-com.github.io](https://cake-com.github.io/pumble-node-sdk/publish-to-marketplace.html))
- Plan gating notes: Free plan allows “Up to 3 apps & integrations,” Pro “Up to 10,” Business “Unlimited” (integration count limits but API available on all plans per API add-on doc). ([pumble.com](https://pumble.com/pricing))

API surface
- api_breadth: moderate — messages, channels, users, workspace, calls, files, drafts, app/home view; events, triggers, and interactive components. ([cake-com.github.io](https://cake-com.github.io/pumble-node-sdk/api-client.html))
- OpenAPI spec: Yes (Swagger/Scalar UI for the API Keys add-on at pumble-api-keys.addons.marketplace.cake.com/api-docs). Unknown/not published for the broader Apps API; SDK docs provide method refs. ([pumble-api-keys.addons.marketplace.cake.com](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/))
- Webhooks/events: Yes — Incoming Webhooks (simple POST URL) and app event deliveries to your server (with optional Socket mode). ([pumble.com](https://pumble.com/help/integrations/add-pumble-apps/incoming-webhooks-for-pumble/?utm_source=openai))
- Sandbox: No separate sandbox found; develop and test in any Pumble workspace you control (private/unpublished app). (No explicit sandbox docs located; SDK shows private app flow.) ([cake-com.github.io](https://cake-com.github.io/pumble-node-sdk/publish-to-marketplace.html))

MCP and integrations
- mcp: official — Pumble hosts an MCP server to connect agents (Claude, Gemini, etc.) using your app key plus user/bot token; tools map to selected scopes. ([pumble.com](https://pumble.com/help/integrations/automation-workflow-integrations/how-to-use-the-pumble-mcp-server/))

Buildability for a Composio agent toolkit
- buildability: ready_with_caveats — Platform is documented with OAuth2 and an official MCP server; you can self-serve credentials today. Caveats: public distribution needs marketplace review; rate limits and plan-based integration counts apply; some APIs (e.g., the lightweight API Keys add-on) are narrower. ([cake-com.github.io](https://cake-com.github.io/pumble-node-sdk/authorization.html))
- blocker: app_review (for a public OAuth app listing; private installs are immediate). ([cake-com.github.io](https://cake-com.github.io/pumble-node-sdk/publish-to-marketplace.html))

Concise evidence (quotes)
- OAuth2 flow | https://cake-com.github.io/pumble-node-sdk/authorization.html | “Pumble uses OAuth2… User clicks ‘Allow’… Using this code and your clientSecret… generate an access token… you will be able to use the Pumble API… curl … https://api-ga.pumble.com/oauth2/access … returns ‘accessToken’ and ‘botToken’.” ([cake-com.github.io](https://cake-com.github.io/pumble-node-sdk/authorization.html))
- API request headers | https://cake-com.github.io/pumble-node-sdk/api-client.html | “Every Request to Pumble API must be sent with two headers: 1. x-app-token… 2. token: The access token of the user or bot.” ([cake-com.github.io](https://cake-com.github.io/pumble-node-sdk/api-client.html))
- API key add-on (self-serve, all plans) | https://pumble.com/help/integrations/automation-workflow-integrations/api-keys-integration/ | “This addon lets you generate an API key that allows you to send messages, reactions, and more via simple HTTP requests… Available on all plans.” ([pumble.com](https://pumble.com/help/integrations/automation-workflow-integrations/api-keys-integration/))
- Incoming webhooks | https://pumble.com/help/integrations/add-pumble-apps/incoming-webhooks-for-pumble/ | “When you create an incoming webhook, you receive a unique URL by which you can send a JSON payload with the message text… The rate limit on incoming webhooks on Pumble is 1 second per webhook.” ([pumble.com](https://pumble.com/help/integrations/add-pumble-apps/incoming-webhooks-for-pumble/?utm_source=openai))
- Marketplace review requirement | https://cake-com.github.io/pumble-node-sdk/publish-to-marketplace.html | “Public apps are available to all Pumble workspaces… If you wish to make your app Public, it needs to go through the review process… ‘Private’ app can be published immediately.” ([cake-com.github.io](https://cake-com.github.io/pumble-node-sdk/publish-to-marketplace.html))
