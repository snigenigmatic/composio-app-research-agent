Here are the integration research notes for Twilio.

- Product: Twilio
- Category: Communications and Messaging
- One‑liner: Cloud CPaaS for programmable messaging, voice, email (SendGrid), WhatsApp and related customer engagement APIs. ([twilio.com](https://www.twilio.com/docs?utm_source=openai))
- Docs URL: https://www.twilio.com/docs ([twilio.com](https://www.twilio.com/docs?utm_source=openai))

Auth
- auth_methods: OAuth2; Basic (HTTP Basic using API Key SID + Secret or Account SID + Auth Token). Twilio now supports OAuth 2.0 (Client Credentials and Authorization Code) for Communications APIs; Basic with API keys remains supported. ([twilio.com](https://www.twilio.com/docs/iam/oauth-apps/overview))
- primary_auth: OAuth2 (recommended for multi‑tenant apps; short‑lived, scoped tokens). ([twilio.com](https://www.twilio.com/docs/iam/oauth-apps/overview))

Access and gating
- access: self_serve_trial (free 30‑day trial; no credit card; real API calls with product‑specific free units). For production, upgrade removes trial limits. ([twilio.com](https://www.twilio.com/docs/usage/trials?_hsmi=6767039))
- app_review: Not generally required for API use; certain channels (e.g., A2P 10DLC, WhatsApp senders) require registrations, but credentials are self‑serve. (Docs emphasize trial/upgrade rather than app reviews.) ([twilio.com](https://www.twilio.com/docs/usage/trials?_hsmi=6767039))
- pricing/plan notes: Trial expires after 30 days; upgrade to pay‑as‑you‑go usage. ([twilio.com](https://www.twilio.com/docs/usage/trials?_hsmi=6767039))

API surface
- api_breadth: broad (dozens of products across multiple subdomains; full CRUD). Twilio publishes OpenAPI specs covering its APIs. ([twilio.com](https://www.twilio.com/docs/openapi/structure-of-twilio-openapi-spec?utm_source=openai))
- OpenAPI spec: Yes (official GitHub repo and docs). ([github.com](https://github.com/twilio/twilio-oai?utm_source=openai))
- Webhooks: Yes (configurable; supports OAuth 2.0, Basic, or Digest for webhook delivery auth; signing supported). ([twilio.com](https://www.twilio.com/docs/usage/webhooks/webhook-configuration-faq))
- Sandbox / testing: Yes (WhatsApp Sandbox) and Test Credentials. ([twilio.com](https://www.twilio.com/docs/whatsapp?utm_source=openai))

MCP (Model Context Protocol)
- mcp: official (hosted Twilio MCP server documented; Public Beta). ([twilio.com](https://www.twilio.com/docs/ai/mcp))

Buildability for an agent toolkit
- buildability: ready_with_caveats — APIs and creds are self‑serve and well‑documented; OAuth2 is GA. Caveats: trial limits and channel compliance (e.g., A2P/WhatsApp) for real‑world messaging; some features may require paid usage. ([twilio.com](https://www.twilio.com/docs/iam/oauth-apps/overview))
- blocker: paid_plan (to move beyond time‑boxed free units and trial restrictions). ([twilio.com](https://www.twilio.com/docs/usage/trials?_hsmi=6767039))

How a developer gets credentials
- Sign up for a Twilio account (free 30‑day trial). Create API Keys in Console (Standard/Main/Restricted) and use API Key SID + Secret with HTTP Basic, or register an OAuth app (Client Credentials or Authorization Code) and exchange for access tokens. ([twilio.com](https://www.twilio.com/docs/usage/trials?_hsmi=6767039))

Notes for Composio
- Preferred multi‑tenant auth: OAuth2 Authorization Code (user‑consented access to a customer’s Twilio account). Client Credentials also available for server‑to‑server integrations. ([twilio.com](https://www.twilio.com/docs/iam/oauth-apps/overview))
- API coverage is extensive; official OpenAPI means rapid client generation and strong automation potential. ([twilio.com](https://www.twilio.com/docs/openapi?utm_source=openai))
- Webhooks and WhatsApp sandbox/test creds simplify local and pre‑production flows. ([twilio.com](https://www.twilio.com/docs/usage/webhooks/webhook-configuration-faq))
