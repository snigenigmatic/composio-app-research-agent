SE Ranking — Research notes for Composio

- Product: SE Ranking is an all‑in‑one SEO/AEO platform with rank tracking, keyword research, competitor/domain analysis, backlinks, site audit, and AI search visibility; it exposes a Data API and a Project API. ([seranking.com](https://seranking.com/api.html?utm_source=openai))
- Docs URL: https://seranking.com/api/how-to-get-api/ (entry to API access, links to Data + Project docs). ([seranking.com](https://seranking.com/api/how-to-get-api/))

Auth
- auth_methods: API key. Requests use Authorization: Token YOUR_API_KEY (or apikey query param). ([seranking.com](https://seranking.com/api/data/getting-started/))
- primary_auth: API key. One key works for both Data and Project APIs. ([seranking.com](https://seranking.com/api/how-to-get-api/))

Access
- access: self_serve_trial. 14‑day standalone API trial with 100,000 free credits; paid plans include monthly credits; add‑on/standalone plans available for higher use. ([help.seranking.com](https://help.seranking.com/hc/en-us/articles/22447958135068-Getting-Started-with-SE-Ranking-s-API))

API surface
- api_breadth: broad (backlinks, domain analysis, keyword research, website audit, AI search visibility, plus project/rank/keywords management). OpenAPI specs for Data, Project, Local Marketing and SE Visible are published. ([seranking.com](https://seranking.com/api/data/?utm_source=openai))

MCP
- mcp: official. SE Ranking publishes an official MCP server and setup docs (including hosted URL). ([seranking.com](https://seranking.com/api/integrations/mcp/?utm_source=openai))

Buildability
- buildability: ready_with_caveats.
- blocker: paid_plan (beyond trial/included monthly credits, sustained use requires buying credits; rate limits apply). ([seranking.com](https://seranking.com/api/how-to-get-api/))

Other implementation notes
- Rate limits: Data API 10 RPS; Project API 5 RPS; trial Data API typically 1 RPS. ([seranking.com](https://seranking.com/api/rate-limits/))
- Pricing/credits: Per‑endpoint unit costs; annual credit bundles and add‑ons documented. ([seranking.com](https://seranking.com/api/data/getting-started/))
- OpenAPI spec: Yes (official GitHub repo). ([github.com](https://github.com/seranking/openapi?utm_source=openai))
- Webhooks: none seen in docs (appears pull‑based with async export/status where relevant). [Couldn’t find a webhook doc; mark as unknown if needed.]
- Sandbox: no separate sandbox; self‑serve 14‑day API trial and monthly included credits serve dev/testing. ([help.seranking.com](https://help.seranking.com/hc/en-us/articles/22447958135068-Getting-Started-with-SE-Ranking-s-API))
