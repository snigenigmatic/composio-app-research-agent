BigCommerce — Research notes (Ecommerce)

- Product description: Open SaaS ecommerce platform with REST/GraphQL Admin and Storefront APIs, app framework, webhooks, and partner marketplace.
- Docs URL: https://docs.bigcommerce.com/developer

Auth
- auth_methods: OAuth2; Bearer/PAT token (store- or app-level access token via X-Auth-Token header). ([docs.bigcommerce.com](https://docs.bigcommerce.com/developer/docs/integrations/apps/guide/auth?utm_source=openai))
- primary_auth: OAuth2 (single‑click app uses OAuth 2.0 Authorization Code Grant). ([docs.bigcommerce.com](https://docs.bigcommerce.com/developer/docs/integrations/apps/guide/auth?utm_source=openai))

Access
- access: self_serve_free (you can create API accounts in any store, including trials; you can register draft OAuth apps and install on stores you own). Production distribution requires partner approval and app review. ([support.bigcommerce.com](https://support.bigcommerce.com/s/article/Store-API-Accounts?language=en_US&utm_source=openai))

API surface
- api_breadth: broad (Admin REST covers Catalog, Content, Management: orders/customers/shipping/tax, Payments, Webhooks, etc.). ([docs.bigcommerce.com](https://docs.bigcommerce.com/developer/api-reference/rest/admin/overview?utm_source=openai))

MCP
- mcp: official (BigCommerce operates official MCP servers: Storefront MCP GA; Store Management MCP early access). ([docs.bigcommerce.com](https://docs.bigcommerce.com/developer/api-reference/mcp/overview/?utm_source=openai))

Buildability for an agent toolkit
- buildability: needs_outreach (you can build and test immediately, but to connect third‑party merchant stores via OAuth you must become an approved Technology Partner and pass app review). ([docs.bigcommerce.com](https://docs.bigcommerce.com/developer/docs/integrations/apps/guide/types-of-apps))
- blocker: partner_program (and associated app_review). ([docs.bigcommerce.com](https://docs.bigcommerce.com/developer/docs/integrations/apps/guide/types-of-apps?utm_source=openai))

Other implementation details
- OpenAPI spec: Yes (official downloadable OpenAPI specs for REST APIs). ([docs.bigcommerce.com](https://docs.bigcommerce.com/developer/api-reference/openapi-specifications?utm_source=openai))
- Webhooks: Yes (v3 webhooks; “Get notified when specific events occur”). ([docs.bigcommerce.com](https://docs.bigcommerce.com/developer/api-reference/rest/integrations/webhooks?utm_source=openai))
- Sandbox: Yes — 15‑day free trial stores; partner sandboxes via Partner Portal. ([bigcommerce.com](https://www.bigcommerce.com/pricing/?utm_source=openai))

Notes
- For single‑merchant or one‑off integrations, store owners can self‑create API accounts and share X‑Auth‑Token credentials; for multi‑tenant SaaS, use OAuth single‑click apps (requires partner approval to distribute beyond your own stores). ([support.bigcommerce.com](https://support.bigcommerce.com/s/article/Store-API-Accounts?language=en_US&utm_source=openai))
- MCP options may enable agent use-cases without a marketplace app (Store Management MCP is early access and controlled via store settings/scopes). Validate availability per store before relying on it. ([docs.bigcommerce.com](https://docs.bigcommerce.com/developer/api-reference/mcp/store-management/?utm_source=openai))
