Squarespace — Ecommerce

Summary
- Product: Squarespace Commerce APIs and Extensions for managing products, orders, inventory, profiles/contacts, transactions; official MCP server for AI assistants.
- One‑liner: Website/ecommerce platform with REST Commerce APIs, webhooks, and an official MCP server to integrate stores and build Extensions.

Auth model
- auth_methods: OAuth2; API key. (Extensions must use OAuth; per‑site API keys also supported.) ([commerce-apis.squarespace.com](https://commerce-apis.squarespace.com/commerce-apis/authentication-and-permissions))
- primary_auth: OAuth2 (for a multi-tenant app/agent acting on a customer’s site). OAuth clients are issued after review via a request form. ([commerce-apis.squarespace.com](https://commerce-apis.squarespace.com/oauth))

Access
- access: app_review (OAuth client registration requires submitting a form and review; per‑site API keys are self‑serve inside a site’s dashboard but gated by plan). ([commerce-apis.squarespace.com](https://commerce-apis.squarespace.com/oauth))

API surface
- api_breadth: moderate (Inventory, Orders, Products, Profiles, Transactions, plus Webhook Subscriptions). ([commerce-apis.squarespace.com](https://commerce-apis.squarespace.com/commerce-apis/overview?utm_source=openai))

MCP
- mcp: official (Squarespace MCP server; remote endpoint provided). ([developers.squarespace.com](https://developers.squarespace.com/mcp/overview))

Buildability for an agent toolkit (Composio)
- buildability: ready_with_caveats
- why: Public, documented REST APIs and official MCP server exist; per‑site API keys are immediate (with paid plan), but scalable user-by-user installs should use OAuth, which requires review/approval. Webhooks are available. ([commerce-apis.squarespace.com](https://commerce-apis.squarespace.com/commerce-apis/authentication-and-permissions))
- blocker: app_review

Key details for implementers
- Plans/entitlements: Squarespace documents API availability by plan; help center indicates Orders/Inventory APIs on current Core/Plus/Advanced plans and legacy Commerce Advanced. Expect paid-plan gating for Commerce APIs. ([support.squarespace.com](https://support.squarespace.com/hc/en-us/articles/236297987-Squarespace-API-keys?utm_source=openai))
- Scopes (OAuth): website.orders, website.products, website.inventory, website.transactions (read/write variants exist). ([commerce-apis.squarespace.com](https://commerce-apis.squarespace.com/oauth))
- Webhooks: Yes. Subscribe via Webhook Subscriptions API; supports Order create/update and Contact events; signed payloads; test delivery endpoint available. ([developers.squarespace.com](https://developers.squarespace.com/commerce-apis/webhooks/overview))
- OpenAPI spec: None found (docs are prose + endpoint references).
- Sandbox: No dedicated sandbox noted; changes affect the live website. Webhooks have a “send test notification” endpoint for testing. ([developers.squarespace.com](https://developers.squarespace.com/mcp/tools/commerce))

Docs URL

What’s possible via API (selected)
- Orders: read; mark fulfillments via appropriate permissions. ([commerce-apis.squarespace.com](https://commerce-apis.squarespace.com/commerce-apis/authentication-and-permissions))
- Products: read/create/update/delete (v2 supports physical, service, gift card, download with noted limits). ([developers.squarespace.com](https://developers.squarespace.com/commerce-apis/changelog?utm_source=openai))
- Inventory: read/write stock. ([commerce-apis.squarespace.com](https://commerce-apis.squarespace.com/commerce-apis/overview?utm_source=openai))
- Profiles/Contacts: read contacts/customers/subscribers; contact webhooks available. ([commerce-apis.squarespace.com](https://commerce-apis.squarespace.com/commerce-apis/overview?utm_source=openai))
