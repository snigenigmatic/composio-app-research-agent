Here’s what I found for Pipedrive (CRM and Sales)

Product
- One‑liner: Sales-focused CRM for managing leads, deals, contacts, activities and pipelines, with an open REST API and developer platform. ([developers.pipedrive.com](https://developers.pipedrive.com/docs/api/v1?trk=public_profile_project-button))
- Docs URL: developers.pipedrive.com/docs/api (API reference and dev portal). ([developers.pipedrive.com](https://developers.pipedrive.com/docs/api/v1?trk=public_profile_project-button))

Auth model
- auth_methods: OAuth2; API key (x-api-token header). ([pipedrive.readme.io](https://pipedrive.readme.io/docs/core-api-concepts-authentication))
- primary_auth: OAuth2 (recommended for apps; tokens issued via oauth.pipedrive.com). ([pipedrive.readme.io](https://pipedrive.readme.io/docs/core-api-concepts-authentication))

Access and gating
- access: self_serve_free (developer sandbox + Developer Hub give you client_id/client_secret without sales contact). ([developers.pipedrive.com](https://developers.pipedrive.com/docs/api/v1?trk=public_profile_project-button))
- Notes on plans: “API access” is included on all plan tiers (old and new). ([support.pipedrive.com](https://support.pipedrive.com/en/article/what-features-do-the-pipedrive-plans-have?category=billing))
- Marketplace/public distribution: public apps require review; private apps don’t need submission (can be shared by direct install link). ([pipedrive.readme.io](https://pipedrive.readme.io/docs/marketplace-app-approval-process))

API surface
- api_breadth: broad (dozens of resources across deals, persons, orgs, activities, products, projects, users, webhooks, etc.). ([developers.pipedrive.com](https://developers.pipedrive.com/docs/api/v1?trk=public_profile_project-button))
- OpenAPI spec: yes (official OpenAPI 3 spec files for v1 and v2). ([developers.pipedrive.com](https://developers.pipedrive.com/docs/api/v1?trk=public_profile_project-button))
- Webhooks: yes (v1/v2; retry policy and ban system documented). ([pipedrive.readme.io](https://pipedrive.readme.io/docs/guide-for-webhooks))
- Sandbox: yes (developer sandbox account to access Developer Hub; inactivity rules documented). ([developers.pipedrive.com](https://developers.pipedrive.com/docs/api/v1?trk=public_profile_project-button))
- Rate limits: token-based daily budget + burst headers; 429 on exceed. ([developers.pipedrive.com](https://developers.pipedrive.com/changelog/post/breaking-changes-token-based-rate-limits-for-api-requests?utm_source=openai))

MCP
- mcp: community (no official server; third parties have published non‑vendor MCP servers). ([reddit.com](https://www.reddit.com/r/mcp/comments/1s2bqw7/pipedrive_mcp_server_enables_users_to_manage/?utm_source=openai))

Buildability for an agent toolkit
- buildability: ready_with_caveats
- Why: You can obtain sandbox and OAuth creds self‑serve; API is broad with OpenAPI and webhooks. Caveats: public Marketplace listing requires app review; token-based rate limits and webhook ban policy need careful handling. ([pipedrive.readme.io](https://pipedrive.readme.io/docs/client-id-and-client-secret))
- blocker: app_review (only if you want a public Marketplace app; private/unlisted distribution is possible without submission). ([pipedrive.readme.io](https://pipedrive.readme.io/docs/marketplace-app-approval-process))

Research notes
- Primary auth flow: OAuth 2.0 authorization code; tokens from oauth.pipedrive.com; refresh via /oauth/token. API token auth available via x-api-token header (token is tied to a specific user/company). ([developers.pipedrive.com](https://developers.pipedrive.com/docs/api/v1/Oauth))
- Getting credentials: Create an app in Developer Hub on a developer sandbox account, then copy client_id and client_secret from the “OAuth & access scopes” tab. ([pipedrive.readme.io](https://pipedrive.readme.io/docs/client-id-and-client-secret))
- Plans and API availability: Knowledge Base tables show “API access” and “Webhooks” are included across all new/old plan tiers. ([support.pipedrive.com](https://support.pipedrive.com/en/article/what-features-do-the-pipedrive-plans-have?category=billing))
- OpenAPI: API reference explicitly offers OpenAPI 3 spec files for both v1 and v2. ([developers.pipedrive.com](https://developers.pipedrive.com/docs/api/v1?trk=public_profile_project-button))
- Webhooks: Retries at 3s/30s/150s; deletion after 3 consecutive days without successful deliveries; separate ban system. ([pipedrive.readme.io](https://pipedrive.readme.io/docs/guide-for-webhooks))
