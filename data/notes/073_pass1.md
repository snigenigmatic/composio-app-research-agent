- one-line description: Linear is a product development and issue tracking system with a public GraphQL API, webhooks, and an official MCP server for agents. ([linear.app](https://linear.app/developers/graphql))
- docs URL: https://linear.app/developers
- OpenAPI spec: No (GraphQL schema via Apollo Studio) ([linear.app](https://linear.app/developers/graphql))
- webhooks: Yes (HMAC-signed via Linear-Signature; admin or admin-scoped app required to manage) ([linear.app](https://linear.app/developers/webhooks))
- sandbox: No dedicated API sandbox (develop against a standard workspace)

Evidence
- Authentication | https://linear.app/developers/graphql | “The Linear API supports personal API keys and OAuth2 authentication.” ([linear.app](https://linear.app/developers/graphql))
- API breadth | https://linear.app/docs/api-and-webhooks | “Linear’s public API is built using GraphQL… In addition to querying, Linear has full support for mutating all entities.” ([linear.app](https://linear.app/docs/api-and-webhooks?_rsc=1234v&utm_source=openai))
- Webhooks | https://linear.app/developers/webhooks | “Only workspace admins, or OAuth applications with the `admin` scope, can create or read webhooks.” ([linear.app](https://linear.app/developers/webhooks))
- Rate limits by plan (implies access on Free) | https://linear.app/developers/rate-limiting | “Requests authenticated using an API key or an OAuth app receive rate limits based on the workspace’s plan… Free, Basic | Standard limits; Business | 2x; Enterprise | 5x.” ([linear.app](https://linear.app/developers/rate-limiting))
- MCP server | https://linear.app/docs/mcp | “The Linear MCP server… The interactive setup flow uses OAuth 2.1… You can also authenticate directly with a bearer token or Linear API key.” ([linear.app](https://linear.app/docs/mcp))

Notes for Composio
- OAuth details: Authorization Code and Client Credentials; supports app actor via actor=app for service/agent behavior. ([linear.app](https://linear.app/developers/oauth-2-0-authentication))
- Personal API keys: sent as Authorization: <API_KEY> header (no Bearer). ([linear.app](https://linear.app/developers/graphql))
- Rate limits: default per-user/hour: API key 2,500 req; OAuth app 5,000 req; complexity limits also apply; limits scale with plan. Consider backoff and webhook-first designs. ([linear.app](https://linear.app/developers/rate-limiting))
- Webhook security: verify HMAC SHA-256 in Linear-Signature and timestamp. ([linear.app](https://linear.app/developers/webhooks))
- GraphQL endpoint: https://api.linear.app/graphql; schema explorable in Apollo Studio. ([linear.app](https://linear.app/developers/graphql))

Overall assessment
- Linear’s API is well-documented, self-serve to start (free workspaces work), and broad enough for a full-featured agent toolkit. Caveats: GraphQL (no OpenAPI), and rate limits vary by plan.
