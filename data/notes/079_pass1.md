Smartsheet — Integration research notes (as of November 24, 2026)

- Product: Smartsheet — collaborative work management and spreadsheet-style project planning for teams.
- Docs URL: https://developers.smartsheet.com

Auth model
- auth_methods: OAuth2; Bearer/PAT token
- primary_auth: OAuth2
- Notes: For end-user, multi-tenant integrations (like Composio), use OAuth 2.0 authorization code (3‑legged). Direct, single-account automations can use a personal access token (static bearer).

Access to credentials / gating
- access: paid_plan
- Details:
  - API access and Developer Tools (for OAuth app registration) require a licensed Smartsheet user on the Business plan or higher.
  - PATs are generated in the Smartsheet UI; OAuth client (client_id/secret) requires Developer Tools registration.
  - No explicit public “app review” step is documented for normal OAuth use; publishing an app profile is optional. Primary gating is plan-based.

API surface
- api_breadth: broad (sheets, rows/cells/columns, reports, dashboards, folders/workspaces, users/groups, search, attachments, webhooks, plan/admin endpoints and more)
- OpenAPI spec: Yes (downloadable OpenAPI YAML provided)
- Webhooks: Yes (sheet- and plan-level event webhooks)
- Sandbox: No dedicated sandbox environment noted; guidance suggests creating a separate “sandbox” Smartsheet account for dev/testing.

MCP (Model Context Protocol)
- mcp: official
- Notes: Smartsheet publishes an official MCP server with toolsets for sheets/rows/columns, portfolios, plan management, workflows, etc., with quickstart and install guides.

Buildability for Composio
- buildability: ready_with_caveats
- Why: Well-documented REST API with OAuth2 and PATs, OpenAPI, webhooks, and an official MCP server. Caveat is plan gating (Business+ license needed) and a required Developer Tools registration for OAuth apps.
- blocker: paid_plan

How to get credentials (summary)
- PAT/Bearer token: In Smartsheet UI → Account → Personal Settings → API Access → Generate new access token. Use Authorization: Bearer <token>.
- OAuth2 (preferred for multi-tenant): Register for Developer Tools (Business+ licensed user), then in Account → Developer Tools create an app to obtain client_id and client_secret; implement standard 3‑legged OAuth to obtain user-scoped tokens with requested scopes.
