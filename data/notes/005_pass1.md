Twenty — CRM and Sales

Product summary
- Open-source, developer-focused CRM that exposes both REST and GraphQL APIs (plus a native MCP server) and can run self-hosted or on Twenty Cloud.

Integration assessment
- auth_methods: OAuth2; API key
- primary_auth: OAuth2
- access: self_serve_trial
- api_breadth: broad
- mcp: official
- buildability: ready_with_caveats
- blocker: paid_plan

Why this classification
- OAuth2 is explicitly supported for connecting apps/assistants; API keys are created in-app and used via Authorization: Bearer. Cloud sign-up is self-serve with a 30‑day free trial; production use requires a paid plan. APIs cover core CRM objects and workspace metadata, and are available over REST and GraphQL. A native MCP server is included on Cloud.

Developer docs and key implementation details
- Docs URL: https://docs.twenty.com/developers/introduction ([docs.twenty.com](https://docs.twenty.com/developers/introduction))
- API surface:
  - Two APIs: Core (/rest, /graphql) for records; Metadata (/rest/metadata, /metadata) for schema and files. Base URL (Cloud): https://api.twenty.com/. ([github.com](https://github.com/twentyhq/twenty/blob/main/packages/twenty-docs/developers/extend/api.mdx?utm_source=openai))
  - OAuth supported for external apps; API keys created in Settings → Developers → API; keys can be role-scoped. ([github.com](https://github.com/twentyhq/twenty/blob/main/packages/twenty-docs/developers/extend/api.mdx?utm_source=openai))
  - Webhooks are available and mentioned across docs/releases. ([docs.twenty.com](https://docs.twenty.com/developers/introduction))
  - Rate limits (Cloud): Pro 50/min, Organization 100/min (enterprise custom). ([twenty.com](https://twenty.com/pricing))
- Auth models:
  - OAuth2: explicitly supported for app connections and MCP clients. ([docs.twenty.com](https://docs.twenty.com/developers/introduction))
  - API key: created in-app; used as Authorization: Bearer. CLI supports browser OAuth login or API key config. ([github.com](https://github.com/twentyhq/twenty/blob/main/packages/twenty-docs/developers/extend/api.mdx?utm_source=openai))
- Getting credentials:
  - Cloud: self-serve signup with a free trial; create API keys under Settings → Developers → API; OAuth flows are available without partner review. ([twenty.com](https://twenty.com/pricing))
  - Self-host: free/open-source; same API endpoints on your domain. ([github.com](https://github.com/twentyhq/twenty/blob/main/packages/twenty-docs/developers/extend/api.mdx?utm_source=openai))
- OpenAPI spec: No single public, static OpenAPI. Docs state “There is no static API reference… each workspace has its own schema,” and workspace-specific docs/playground are generated. ([github.com](https://github.com/twentyhq/twenty/blob/main/packages/twenty-docs/developers/extend/api.mdx?utm_source=openai))
- Webhooks: Yes (documented and in releases). ([twenty.com](https://twenty.com/releases?utm_source=openai))
- Sandbox/dev environment: Yes. In-app API Playground; local/self‑hosted environments; CLI can start a local server and authenticate via OAuth or API key. Pricing page also lists “Environments: Local, Production.” ([docs.twenty.com](https://docs.twenty.com/l/de/developers/extend/apps/cli-and-testing?utm_source=openai))

Build considerations for a Composio toolkit
- Ready with caveats:
  - Per‑tenant schema: endpoints and GraphQL types reflect each workspace’s custom objects; avoid relying on a fixed OpenAPI. Use GraphQL introspection or generic REST patterns and allow dynamic object names. ([github.com](https://github.com/twentyhq/twenty/blob/main/packages/twenty-docs/developers/extend/api.mdx?utm_source=openai))
  - Cloud API rate limits: 50–100 req/min by plan; batch up to 60 records/call to mitigate. ([twenty.com](https://twenty.com/pricing))
  - Access/cost: after the free trial, Cloud is paid; self-host remains free if users run their own instance. ([twenty.com](https://twenty.com/pricing))
  - MCP is native and OAuth-enabled, which can simplify AI client integrations but still requires handling OAuth discovery/registration. ([twenty.com](https://twenty.com/))
