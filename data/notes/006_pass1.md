Podio — Integrations research notes

- Product: Podio (Progress) — customizable work management/CRM platform where teams build apps and workflows; API exposes most of the product.
- Docs URL: https://developers.podio.com (API reference and auth) ([developers.podio.com](https://developers.podio.com/?utm_source=openai))

Auth model
- auth_methods: OAuth2 (supports server-side, client-side, username/password, and “app authentication” with app_id + app_token that still mints OAuth2 access tokens). ([developers.podio.com](https://developers.podio.com/authentication?utm_source=openai))
- primary_auth: OAuth2. ([developers.podio.com](https://developers.podio.com/authentication?utm_source=openai))
- Notes: App authentication is intended for integrations that act on a single Podio app without a user context. Tokens are standard OAuth2 bearer tokens with refresh support. Access token ~8h; refresh token ~28 days. ([developers.podio.com](https://developers.podio.com/authentication?utm_source=openai))

Access to credentials / gating
- access: self_serve_free — any user can sign in/sign up and generate API keys in account settings; API usable on both free and paid accounts within base limits. ([developers.podio.com](https://developers.podio.com/api-key))
- Notable caveats:
  - Programmatic retrieval of app tokens and some destructive operations require support approval/increased “trust level.” ([developers.podio.com](https://developers.podio.com/index/faq))
  - Throughput above base limits requires paid API Add‑on tiers. ([d117h1jjiq768j.cloudfront.net](https://d117h1jjiq768j.cloudfront.net/podio/pricing))

API surface
- api_breadth: broad — many “areas” (applications, items, tasks, files, users, spaces, hooks/webhooks, search, etc.), with full CRUD across core objects. ([developers.podio.com](https://developers.podio.com/doc?utm_source=openai))

Eventing / webhooks
- Webhooks: yes — “Hooks are webhooks that can call external sites when certain actions occur in Podio.” Only ports 80/443 supported. ([developers.podio.com](https://developers.podio.com/doc/hooks?utm_source=openai))

Rate limits and pricing notes
- Base API limits: two-limit model per API key, rolling hour — Limit A 250/hr for resource‑intensive calls; Limit B 1,000/hr standard calls. Errors return HTTP 420 with X‑Rate‑Limit headers. ([developers.podio.com](https://developers.podio.com/index/limits?utm_source=openai))
- Pricing page shows “API Integrations: 1,000 calls per hour” across plans; paid “API” Add‑ons increase hourly capacity (tiers up to 50,000/hr listed). ([d117h1jjiq768j.cloudfront.net](https://d117h1jjiq768j.cloudfront.net/podio/pricing))

MCP (Model Context Protocol)
- mcp: official — Progress documents an official hosted Podio MCP server at mcp.podio.com (beta), with 20+ tools; supports OAuth sign‑in and can use your own Podio API key. ([progress.com](https://www.progress.com/podio/documentation/using-podio/ai-and-mcp/podio-mcp-server-integration-guide))

Buildability for an agent toolkit (Composio)
- buildability: ready_with_caveats
  - Rationale: Self‑serve OAuth2 credentials and comprehensive REST API with webhooks make it straightforward. Caveats: relatively tight base rate limits unless the customer purchases API Add‑ons; some sensitive operations and programmatic app-token access require support approval. ([developers.podio.com](https://developers.podio.com/index/limits?utm_source=openai))
- blocker: none

Other implementation details
- Protocol/format: HTTPS REST+JSON; SSL mandatory. ([developers.podio.com](https://developers.podio.com/index/api?utm_source=openai))
- OpenAPI spec: none official published in Podio’s docs (not found in developers.podio.com).
- Sandbox: no dedicated sandbox found; use a free or trial org for development. ([developers.podio.com](https://developers.podio.com/index/faq))
