Here are the integration research notes for Pinterest.

- auth_methods: OAuth2
- primary_auth: OAuth2
- access: app_review
- api_breadth: broad
- mcp: none known (vendor has announced an official MCP server but it is not launched yet)
- buildability: ready_with_caveats
- blocker: app_review

Product description: Pinterest API v5 lets apps create/manage organic Pins and Boards, manage and report on ads, catalogs and conversions, and pull analytics for creators, advertisers and merchants.

Docs URL: https://developer.pinterest.com

OpenAPI spec: Yes (official OpenAPI 3.0 repo)

Webhooks: Yes (Lead Ads webhook subscriptions; Pinterest delivers encrypted lead data to your callback URL)

Sandbox: Yes (API Sandbox with test tokens and separate sandbox host/api-sandbox; trial-created entities are sandbox-only/creator-visible)

Notes on auth and gating
- OAuth 2.0 Authorization Code and Client Credentials grants; bearer tokens used on API requests.
- You must create or log into a Pinterest Business account, accept Developer Terms, request Trial access (reviewed by Pinterest), then upgrade to Standard access (additional review incl. demo video) for production-scale features and higher rate limits. Trial-created Pins/Boards are sandbox-only/creator-visible.
- Some features (e.g., Lead Ads) require additional enablement via a Pinterest account team.

Why buildability = ready_with_caveats
- Credentials and a working integration are achievable self-serve, but production usage and higher rate limits need Pinterest app review; certain features (Lead Ads) require account team approval. Rate limits and access tiering can constrain multi-tenant agent usage.

Key capabilities surface (examples)
- Organic: pins, boards, media, user_account.
- Ads: ad_accounts, campaigns, ad_groups, ads, analytics, bulk, labels, schedules.
- Targeting: audiences, customer_lists, keywords, audience_insights, audience_sharing.
- Shopping: catalogs, feeds, items, product groups, reports.
- Conversions: conversion_tags, events/CAPI endpoints.
- Lead Ads: lead_forms, lead_ads, leads_export, lead ad subscriptions (webhooks).
