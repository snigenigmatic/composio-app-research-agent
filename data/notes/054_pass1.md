MrScraper — research notes (2026-11-24)

- Product: MrScraper
- One-line description: AI-powered web scraping platform with a Scraper API, a Platform API to create/rerun/manage scrapers and results, marketplace endpoints, web search, proxies, and webhooks. ([docs.mrscraper.com](https://docs.mrscraper.com/docs/api/overview?utm_source=openai))
- Docs URL: https://docs.mrscraper.com (API overview and guides). ([docs.mrscraper.com](https://docs.mrscraper.com/docs/api/overview?utm_source=openai))

Auth
- auth_methods: Bearer/PAT token; OAuth2 (MCP server only). ([docs.mrscraper.com](https://docs.mrscraper.com/docs/api/authentication?utm_source=openai))
- primary_auth: Bearer/PAT token (x-api-token header; some endpoints also accept Authorization: Bearer). ([docs.mrscraper.com](https://docs.mrscraper.com/docs/api/authentication?utm_source=openai))

Access and gating
- access: self_serve_free (free signup yields API token; “no credit card required”). Note: docs conflict on monthly free tokens (1,000 on pricing page vs. 100 on billing page). ([mrscraper.com](https://mrscraper.com/pricing?utm_source=openai))
- app review: not indicated for API usage.
- paid tiers: available for higher quotas/limits. ([mrscraper.com](https://mrscraper.com/pricing?utm_source=openai))

API surface
- api_breadth: moderate (core scraping, scrapers/results management, marketplace, analytics, web search). ([docs.mrscraper.com](https://docs.mrscraper.com/docs/api/overview?utm_source=openai))
- Notable caveat: “For access to endpoints on other hosts, please contact support to request an API token.” ([docs.mrscraper.com](https://docs.mrscraper.com/docs/api/authentication?utm_source=openai))

MCP
- mcp: official (published by MrScraper; hosted Streamable HTTP endpoint using OAuth 2.1, plus open-source server). ([docs.mrscraper.com](https://docs.mrscraper.com/docs/getting-started/mcp-server?utm_source=openai))

Buildability for Composio
- buildability: ready (self-serve creds + documented REST API and official MCP). Caveats: free-tier token limits; some hosts may require support-issued tokens. ([docs.mrscraper.com](https://docs.mrscraper.com/docs/api/authentication?utm_source=openai))
- blocker: none.

Spec, webhooks, sandbox
- OpenAPI spec: not found for the core REST APIs; an OpenAPI 3.1 JSON spec exists for the Circle/x402 pay-per-request gateway only. ([docs.mrscraper.com](https://docs.mrscraper.com/docs/integrations/x402/circle?utm_source=openai))
- Webhooks: yes (events on scrape started/completed/failed; set via dashboard). ([docs.mrscraper.com](https://docs.mrscraper.com/docs/integrations/webhook?utm_source=openai))
- Sandbox: no dedicated sandbox environment documented; free plan serves as dev/testing. ([mrscraper.com](https://mrscraper.com/pricing?utm_source=openai))
