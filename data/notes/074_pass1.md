App: Jira (Atlassian)
Category: Productivity and Project Management

Product brief
- Jira Cloud is Atlassian’s work management and issue/project tracking platform; its Cloud REST APIs cover platform objects (issues, projects, users, workflows, JQL, webhooks, etc.) plus Jira Software agile resources (boards, sprints, backlogs). ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/rest/v2/))

Auth model
- auth_methods: OAuth2; Basic (with Atlassian account email + API token); JWT/service account (for Atlassian Connect apps) ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/oauth-2-3lo-apps/?utm_source=openai))
- primary_auth: OAuth2 (3LO via the Atlassian Developer Console) — recommended by Atlassian for external integrations. ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/security-for-other-integrations/?utm_source=openai))

Access to credentials
- access: self_serve_free — create OAuth 2.0 (3LO) apps and enable sharing directly in the Atlassian Developer Console; no marketplace listing required for private distribution. ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/oauth-2-3lo-apps/?utm_source=openai))

API surface
- api_breadth: broad — the Jira Cloud REST API spans many resource groups (issues, projects, users, workflows, webhooks and more), plus Jira Software agile entities (board, sprint, backlog, etc.). ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/rest/v2/))

MCP (Model Context Protocol)
- mcp: official — Atlassian publishes an official, hosted “Rovo MCP Server” and an open-source repo. ([developer.atlassian.com](https://developer.atlassian.com/cloud/rovo-mcp/guides/getting-started/?utm_source=openai))

Buildability for an agent toolkit (Composio)
- buildability: ready — OAuth 2.0 (3LO) creds are self-serve; APIs and webhooks are well-documented; official MCP server also exists if an MCP-based route is desired. Note: Atlassian advises against collecting user API tokens or asking customers to create their own 3LO apps; register your own 3LO app and request scopes instead. ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/oauth-2-3lo-apps/?utm_source=openai))
- blocker: none

Key implementation notes
- Scopes and consent: OAuth 2.0 (3LO) uses user consent and scopes; calls go via api.atlassian.com with the site’s cloudId. ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/software/oauth-2-3lo-apps/?utm_source=openai))
- Alternate auth for scripts: Basic auth with API token exists but is discouraged for general integrations. ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/basic-auth-for-rest-apis/?trk=article-ssr-frontend-pulse_little-text-block&utm_source=openai))
- Webhooks: First-party webhooks let you subscribe to issue and other events. ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/webhooks/?utm_source=openai))
- Dev/sandbox: Atlassian offers free Cloud developer sites (Cloud Developer Bundle) for testing. ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/project-activity/?utm_source=openai))

Docs URL
- https://developer.atlassian.com/cloud/jira/platform/ (platform overview and REST API entry point). ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/index/?utm_source=openai))

OpenAPI spec, webhooks, sandbox
- OpenAPI spec: Yes — OpenAPI links are provided in the Jira Cloud REST API references. ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/rest/v3/?utm_source=openai))
- Webhooks: Yes — platform and Jira Software webhook docs exist. ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/webhooks/?utm_source=openai))
- Sandbox/dev site: Yes — free Cloud developer site with Jira and Confluence for building/testing. ([developer.atlassian.com](https://developer.atlassian.com/cloud/jira/platform/project-activity/?utm_source=openai))
