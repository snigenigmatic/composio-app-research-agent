Auth model

Access (how a developer gets credentials)
- access: self_serve_free

Other operational details (useful for agents/integrations)
- Rate limits (OAuth API v2): 100 requests/10s burst; 200,000/day per app and resource; headers provided. ([help.gohighlevel.com](https://help.gohighlevel.com/support/solutions/articles/48001060529-highlevel-api-documentation?fp_ref=getfreetrail&fp_sid=api-facts))
- OAuth token model: short‑lived access token (~24h) + refresh token (valid up to 1 year, rotates on use). ([marketplace.gohighlevel.com](https://marketplace.gohighlevel.com/docs/Authorization/OAuth2.0/index.html))
- PIT guidance: intended for internal/single‑subaccount use; generate via UI or programmatically. ([marketplace.gohighlevel.com](https://marketplace.gohighlevel.com/docs/Authorization/authorization_doc/))
- v1 API keys: legacy/deprecated; new key creation no longer supported. ([help.gohighlevel.com](https://help.gohighlevel.com/support/solutions/articles/155000003697-api-security-initiatives?utm_source=openai))

Notes and caveats for Composio
- For multi‑tenant agent actions on customers’ accounts, prefer OAuth2 via a Marketplace app (PIT is best for one‑tenant/internal tooling).
- If you plan to list a public integration, factor in Marketplace review and distribution‑type policies (private app install limits, scope justification). ([marketplace.gohighlevel.com](https://marketplace.gohighlevel.com/docs/MarketplacePolicies/PrivateAppInstallLimits/index.html?utm_source=openai))
