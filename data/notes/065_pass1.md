Supabase — Integration Research Notes

- Product: Supabase
- One‑liner: Open‑source Firebase alternative providing a hosted Postgres database with auto‑generated REST/GraphQL APIs, Auth, Storage, Realtime, Functions, and a Management API. ([supabase.com](https://supabase.com/docs/guides/api?utm_source=openai))
- Docs: https://supabase.com/docs

Auth model
- auth_methods: OAuth2; API key; Bearer/PAT token (personal access token)
  - Management API supports OAuth2 and PATs in Authorization: Bearer. ([supabase.com](https://supabase.com/docs/reference/api/introduction))
  - Project APIs use project-scoped API keys (publishable/secret; replacing legacy anon/service_role). ([supabase.com](https://supabase.com/docs/guides/getting-started/api-keys?trk=article-ssr-frontend-pulse_little-text-block))
- primary_auth (for a multi-tenant agent acting on a customer’s Supabase account): OAuth2 (create an OAuth App; user consents; short‑lived scoped tokens). ([supabase.com](https://supabase.com/docs/guides/integrations/build-a-supabase-oauth-integration))

Access to credentials
- access: self_serve_free
  - Anyone can create a free org/project and obtain API keys; pricing page lists “Unlimited API requests” on Free. ([supabase.com](https://supabase.com/pricing?utm_source=openai))
  - Developers self‑serve PATs from their account and can create OAuth Apps in the dashboard. ([supabase.com](https://supabase.com/docs/reference/api/introduction))

API surface area
- api_breadth: broad (Data REST API via PostgREST, GraphQL, Realtime WS, Storage, Auth, Edge Functions, plus extensive Management API endpoints). ([supabase.com](https://supabase.com/docs/guides/api?utm_source=openai))

Model Context Protocol (MCP)
- mcp: official (Supabase provides an official MCP server and docs). ([supabase.com](https://supabase.com/features/mcp-server?utm_source=openai))

Buildability for Composio
- buildability: ready — public docs, self‑serve OAuth + PATs + project keys; wide, well‑documented APIs.
- blocker: none
- Notable caveats for agents:
  - Project keys are highly privileged (secret key bypasses RLS); prefer OAuth2 for Management API and minimize use of secret keys. Legacy anon/service_role keys are being deprecated by end of 2026. ([supabase.com](https://supabase.com/docs/guides/getting-started/api-keys?trk=article-ssr-frontend-pulse_little-text-block))

MCP note
- Supabase also documents deploying app‑owned MCP servers on Edge Functions; separate from the “Supabase MCP server” that connects your coding agent to your project. ([supabase.com](https://supabase.com/docs/guides/ai-tools/byo-mcp?utm_source=openai))

Extras
- OpenAPI spec: yes — PostgREST OpenAPI available via Management API endpoint “Get PostgREST OpenAPI spec.” ([supabase.com](https://supabase.com/docs/reference/api/v1-get-database-openapi?utm_source=openai))
- Webhooks: yes — Database Webhooks (table INSERT/UPDATE/DELETE to HTTP) and Platform Webhooks. ([supabase.com](https://supabase.com/docs/guides/database/webhooks?utm_source=openai))
- Sandbox: no separate sandbox; Free plan projects serve as the dev environment with self‑serve credentials. ([supabase.com](https://supabase.com/pricing?utm_source=openai))
