Close (close.com) — CRM and Sales

Summary
- Product: Close is a sales CRM with built‑in calling, email, SMS, automation/workflows, and AI features for SMB sales teams.
- Docs URL: https://developer.close.com
- Auth model: OAuth 2.0 and API key via HTTP Basic (API key as username, blank password)
- Primary auth for multi‑tenant agents: OAuth2
- Access to credentials: self_serve_trial (14‑day free trial; create API keys and OAuth apps in Settings)
- API breadth: broad (core CRM objects, activities, config, webhooks, reporting, automation, etc.)
- MCP: official (vendor‑published remote MCP server)
- Buildability: ready_with_caveats
- Blocker: app_review (public OAuth app/listing requires Close review)
- OpenAPI spec: Yes (experimental) at https://api.close.com/api/openapi.json
- Webhooks: Yes (event subscriptions with HMAC signatures)
- Sandbox: No separate sandbox documented; use a trial or a separate org

Why these classifications
- Developers can self‑serve: create API keys (Settings → Developer → API Keys) and register OAuth apps; a 14‑day free trial is available. For a public, multi‑tenant integration, Close says private OAuth apps must be requested to be made public/listed, which implies platform review.
- The API surface covers dozens of resources across Leads, Contacts, Opportunities, Tasks, Activities (calls/emails/SMS/meetings/notes/etc.), configuration, reporting, automation, events, and webhooks.
- Close publishes an official MCP server with OAuth 2.0 DCR and API‑key header support.
