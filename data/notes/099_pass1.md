YouTube Transcript (TranscriptAPI) — research notes

- primary_auth: Bearer/PAT token. “Include your API key in the Authorization header… Authorization: Bearer YOUR_API_KEY.” ([transcriptapi.com](https://transcriptapi.com/docs/api/))
- auth_methods: Bearer/PAT token. ([transcriptapi.com](https://transcriptapi.com/docs/api/))
- access: self_serve_free. New accounts start with free credits; no card required. Note: docs show 20 free credits; some pages/promos mention 100 — appears inconsistent. ([transcriptapi.io](https://transcriptapi.io/docs))
- api_breadth: moderate (transcripts plus search, channels, playlists, and video metadata). ([transcriptapi.com](https://transcriptapi.com/swagger?utm_source=openai))
- mcp: official (vendor-hosted MCP server). ([transcriptapi.com](https://transcriptapi.com/docs/mcp/?utm_source=openai))
- buildability: ready — keys are self-serve and API is fully documented; no app review needed. ([transcriptapi.com](https://transcriptapi.com/signup?utm_source=openai))
- blocker: none

One-line product description:
- Hosted REST API (and hosted MCP server) for pulling YouTube captions/transcripts as JSON, plus discovery endpoints for search, channels, playlists, and video metadata; optional channel webhooks. ([transcriptapi.com](https://transcriptapi.com/swagger?utm_source=openai))
