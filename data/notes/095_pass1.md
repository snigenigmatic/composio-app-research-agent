Reducto — Research notes

- Product: Reducto (reducto.ai)
- One‑liner: Agentic document platform with APIs to parse, extract, classify, split, and edit documents into structured, LLM‑ready data.
- Docs: https://docs.reducto.ai/ ([docs.reducto.ai](https://docs.reducto.ai/?utm_source=openai))

Auth model
- auth_methods: API key
- primary_auth: API key
  - Evidence it’s passed as a Bearer token header. ([docs.reducto.ai](https://docs.reducto.ai/configs/parse/settings?utm_source=openai))

Access and gating
- access: self_serve_trial
  - Self‑serve API key with $150 in free usage on the Standard plan; higher tiers via sales. ([reducto.ai](https://reducto.ai/pricing?utm_source=openai))
- Notes: No OAuth app review flow mentioned; keys are created in Studio and used directly. ([reducto.ai](https://reducto.ai/developers?utm_source=openai))

API surface
- api_breadth: moderate (core document operations: parse, extract, classify, split, edit; uploads, jobs, webhooks)
  - Developer page lists the five main endpoints; site pages describe sync/async and webhooks. ([reducto.ai](https://reducto.ai/developers?utm_source=openai))

MCP
- mcp: official
  - Docs advertise an MCP server; a maintained PyPI package exists with provenance from github.com/reductoai. ([docs.reducto.ai](https://docs.reducto.ai/office?utm_source=openai))

Buildability for Composio
- buildability: ready
- blocker: none
  - Rationale: Self‑serve keys, documented REST API and SDKs, OpenAPI spec advertised, webhooks available. ([reducto.ai](https://reducto.ai/developers?utm_source=openai))

Other implementation details
- OpenAPI spec: Yes (vendor states “Full OpenAPI spec with request/response schemas”). ([reducto.ai](https://reducto.ai/developers?utm_source=openai))
- Webhooks: Yes (Svix‑backed destinations; configure via POST /configure_webhook; async job notifications). ([docs.reducto.ai](https://docs.reducto.ai/contextual-schema-optimization/api?utm_source=openai))
- Sandbox: No separate sandbox environment documented; use production API with free trial credits on Standard tier. ([reducto.ai](https://reducto.ai/pricing?utm_source=openai))

Notes and uncertainties
- OAuth2 is not documented; the platform uses API keys as Bearer tokens. If an OAuth program exists elsewhere, it isn’t surfaced in current docs. Confidence: high.
- No explicit “sandbox” or separate test environment found; development appears to use production endpoints with free credits. Confidence: medium.
