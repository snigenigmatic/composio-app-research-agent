Coda (Superhuman Docs) — Integration research notes

- Product: Coda (now branded “Superhuman Docs”) is an all‑in‑one docs platform combining pages, tables/databases, automations, and integrations. ([coda.io](https://coda.io/developers/apis/v1))
- Docs URL: https://coda.io/developers/apis/v1 (Superhuman Docs API v1). ([coda.io](https://coda.io/developers/apis/v1))
- API surface (api_breadth): broad — resources for docs, folders, pages, tables, rows, columns, formulas, controls, ACL, publishing, automations. ([coda.io](https://coda.io/developers/apis/v1))
- Auth methods: Bearer/PAT token; OAuth2 (MCP connectors only). For REST, requests use Authorization: Bearer <token>. MCP can be connected via OAuth 2 in certain clients or via Personal Access Tokens. ([coda.io](https://coda.io/developers/apis/v1))
- Primary auth: Bearer/PAT token. ([coda.io](https://coda.io/developers/apis/v1))
- Access (how to get creds): self_serve_free — any user can generate API tokens in account settings; API is “available to all… free of charge” on free and paid workspaces. ([help.coda.io](https://help.coda.io/hc/en-us/articles/39555941038349-Does-Coda-have-an-API?utm_source=openai))
- MCP: official — vendor‑hosted MCP server at https://coda.io/apis/mcp, documented by Coda/Superhuman. ([help.coda.io](https://help.coda.io/hc/en-us/articles/44722661982989-Connect-to-the-Coda-MCP))
- OpenAPI spec: Yes — official OpenAPI 3.0 (YAML/JSON) provided in the reference. ([coda.io](https://coda.io/developers/apis/v1))
- Webhooks: Incoming only — API supports triggering “webhook‑invoked automations” (POST with Bearer auth) into a specific doc; no general outbound event webhooks documented. ([coda.io](https://coda.io/developers/apis/v1))
- Sandbox: No separate sandbox; use your own workspace/docs. API is available on Free plan with rate limits. ([coda.io](https://coda.io/developers/apis/v1))
- Notable limits: API rate limits are documented; docs over 125 MB may not be able to access the API. ([coda.io](https://coda.io/developers/apis/v1))
- Buildability (Composio): ready_with_caveats — fully documented, self‑serve tokens and broad REST API; official MCP. Caveats: no general self‑serve OAuth for REST (users must paste PATs), API rate limits, and large docs (>125 MB) can’t use API. ([coda.io](https://coda.io/developers/apis/v1))
- Blocker: none

Auth model details
- How a developer gets credentials: In Superhuman Docs account settings → API connections → Generate API token; choose permission (read only/write only/read+write) and scope (all content vs selected docs/tables; can also include MCP). ([help.coda.io](https://help.coda.io/hc/en-us/articles/39555941038349-Does-Coda-have-an-API?utm_source=openai))
- How requests authenticate: HTTP Authorization header with Bearer token. ([coda.io](https://coda.io/developers/apis/v1))
