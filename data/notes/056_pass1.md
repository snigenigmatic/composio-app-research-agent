Here are my integration research notes for Firecrawl.

Product
- One-line: Web data API for AI agents to search, scrape, crawl, map, parse and interact with the live web, returning clean Markdown or structured JSON; official MCP server included. ([github.com](https://github.com/firecrawl/firecrawl/blob/main/README.md?utm_source=openai))
- Category: Data, SEO and Scraping

Auth model
- auth_methods: API key; OAuth2; None (keyless for limited endpoints) ([github.com](https://github.com/firecrawl/firecrawl/blob/main/README.md?utm_source=openai))
- primary_auth: API key (Authorization: Bearer fc-XXXX) for multi-tenant toolkits. ([github.com](https://github.com/firecrawl/firecrawl/blob/main/README.md?utm_source=openai))

Access (how to get credentials)
- access: self_serve_free — 1,000 free credits/month, no card required; higher plans self-serve. Keyless calls are also allowed for basic usage. Effective Sep 4, 2026. ([firecrawl.dev](https://www.firecrawl.dev/pricing?dub_id=qCi7uGk8aC272MOS&via=aliakbar&utm_source=openai))

API surface
- Core endpoints include /v2/search, /v2/scrape, /v2/crawl, /v2/map, /v2/parse, /v2/extract, /v2/interact, and batch variants; “Monitor” and “Agent” features exist as well. Official OpenAPI is published. ([github.com](https://github.com/firecrawl/firecrawl/releases?utm_source=openai))
- api_breadth: moderate (focused set of powerful web-data actions rather than dozens of CRUD resources)

MCP
- mcp: official — hosted server at mcp.firecrawl.dev with OAuth sign-in or API-key mode; first‑party setup guides. ([firecrawl.dev](https://www.firecrawl.dev/blog/firecrawl-mcp-in-cursor?utm_source=openai))

Buildability
- buildability: ready — public docs and SDKs, self-serve keys, and an official MCP server; free tier supports immediate development. ([github.com](https://github.com/firecrawl/firecrawl/blob/main/README.md?utm_source=openai))
- blocker: none

Docs and developer assets
- Docs URL: https://docs.firecrawl.dev (referenced throughout official repos/posts) ([github.com](https://github.com/firecrawl/firecrawl-docs/blob/main/v0/introduction.mdx?utm_source=openai))
- OpenAPI spec: Yes (v2 OpenAPI JSON in the firecrawl-docs repo). ([github.com](https://github.com/firecrawl/firecrawl-docs/blob/main/v1/api-reference/v2-openapi.json?utm_source=openai))
- Webhooks: Yes — crawl webhooks and signed monitor webhooks supported. ([github.com](https://github.com/firecrawl/firecrawl-docs/blob/main/v1-welcome.mdx?utm_source=openai))
- Sandbox: No separate hosted sandbox; instead, free/keyless dev access plus “Firecrawl Local” single binary that serves the same v2 API on localhost (no key). ([github.com](https://github.com/firecrawl/firecrawl?utm_source=openai))

Notes on gating and usage
- Free monthly credits and keyless mode enable instant prototyping; scale and certain advanced modes consume credits per pricing table. ([firecrawl.dev](https://www.firecrawl.dev/pricing?dub_id=qCi7uGk8aC272MOS&via=aliakbar&utm_source=openai))
