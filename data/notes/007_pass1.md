Zoho CRM — Integrations research notes

- One‑line description: Cloud CRM for sales teams to manage leads, deals, automation, and analytics.
- Docs URL: https://www.zoho.com/crm/developer/docs/api/v8/ (primary), https://api-console.zoho.com (API console)

Auth and access
- auth_methods: OAuth2. primary_auth: OAuth2. ([zoho.com](https://www.zoho.com/crm/developer/docs/api/v8/oauth-overview.html?cxsrc_param=crm-solutions&srcPlan=NewCRM))
- access: self_serve_free (free plan includes API calls; OAuth clients can be created self‑serve in the API Console). ([zoho.com](https://www.zoho.com/en-us/crm/zohocrm-pricing.html?src=remoteReady))

API surface
- api_breadth: broad (core CRUD, metadata, bulk, query/COQL, notifications, automation/actions, etc.). ([zoho.com](https://www.zoho.com/crm/developer/docs/api/v8/?utm_source=openai))
- Notable features: region‑specific API domains (US/EU/IN, etc.). ([zoho.com](https://www.zoho.com/crm/developer/docs/api/v8/multi-dc.html?utm_source=openai))

MCP server availability
- mcp: community (e.g., CData’s MCP Server for Zoho CRM). ([cdn.cdata.com](https://cdn.cdata.com/help/CZK/mcp/default.htm))

Buildability
- buildability: ready_with_caveats
- blocker: none
- Caveats to note:
  - API credit limits by edition; additional credits purchasable. ([zoho.com](https://www.zoho.com/crm/developer/docs/api/v8/api-limits.html?utm_source=openai))
  - Multi‑DC endpoints (.com/.eu/.in) must be handled. ([zoho.com](https://www.zoho.com/crm/developer/docs/api/v8/multi-dc.html?utm_source=openai))

Webhooks, OpenAPI, sandbox
- webhooks: yes (workflow webhooks via REST endpoints + Notification APIs). ([zoho.com](https://www.zoho.com/crm/developer/docs/api/v8/create-webhook.html))
- OpenAPI spec: yes (V8 introduces OAS 3.0). ([zoho.com](https://www.zoho.com/crm/developer/docs/api/v8/whats-new.html))
- sandbox: yes (multiple sandbox types; Enterprise/Ultimate availability). ([help.zoho.com](https://help.zoho.com/portal/en/kb/crm/data-administration/sandbox/articles/creating-sandbox))

Product and plan gating summary
- Pricing/plan note: Zoho CRM Free (3 users) includes API with 5,000 calls/day; higher editions include larger base credits; more credits can be purchased. ([zoho.com](https://www.zoho.com/en-us/crm/zohocrm-pricing.html?src=remoteReady))

Why we rated buildability “ready_with_caveats”
- Self‑serve OAuth and free‑tier API access make it implementable today, but:
  - Daily credit limits vary by edition; heavy usage may require purchasing credits. ([zoho.com](https://www.zoho.com/crm/developer/docs/api/v8/api-limits.html?utm_source=openai))
  - You must route calls to the correct regional API domain. ([zoho.com](https://www.zoho.com/crm/developer/docs/api/v8/multi-dc.html?utm_source=openai))
