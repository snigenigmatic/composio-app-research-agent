Here are the research notes for Xero.

- Product: Cloud accounting platform for small and mid-sized businesses (invoicing, bank reconciliation, reporting, payroll add-ons), with a mature developer platform.
- Docs URL: https://developer.xero.com
- Auth methods: OAuth2 (Authorization Code with PKCE; also OAuth2 Client Credentials for certain non‑tenanted endpoints). ([developer.xero.com](https://developer.xero.com/documentation/guides/oauth2/overview?utm_source=openai))
- Primary auth: OAuth2.
- Access: self_serve_free (Starter plan is free; create an app and get credentials; higher tiers are self-serve paid). ([developer.xero.com](https://developer.xero.com/pricing))
- API breadth: broad (Accounting, Files, Assets, Projects, Payroll by region, Bank Feeds, Finance, App Store/Marketplace scopes). ([developer.xero.com](https://developer.xero.com/documentation/guides/oauth2/scopes/?utm_source=openai))
- MCP: official (Xero-hosted Remote MCP server and tooling). ([developer.xero.com](https://developer.xero.com/ai?utm_source=openai))
- Webhooks: yes (first‑class support). ([developer.xero.com](https://developer.xero.com/documentation/guides/webhooks/overview?utm_source=openai))
- Sandbox: demo company available for testing; no separate sandbox environment. ([developer.xero.com](https://developer.xero.com/documentation/best-practices/api-call-efficiencies/rate-limits?utm_source=openai))
- OpenAPI spec: yes (official repo). ([github.com](https://github.com/XeroAPI/Xero-OpenAPI?utm_source=openai))
- Pricing/plan gating highlights:
  - Plans: Starter (free, up to 5 connections), Core (50), Plus (1,000), Advanced (10,000), Enterprise (no limit). Starter is “No charge”; Core/Plus/Advanced have monthly AUD fees. ([developer.xero.com](https://developer.xero.com/pricing))
  - Rate limits per plan (per org/day): 1,000 on Starter; 5,000 on Core and above. ([developer.xero.com](https://developer.xero.com/pricing))
  - App Certification required for Plus/Advanced/Enterprise; security assessment for some premium features (e.g., Journals, XPM API, Bulk Connections). ([developer.xero.com](https://developer.xero.com/pricing))
  - Certain APIs (e.g., Bank Feeds) are partner/certification gated. ([developer.xero.com](https://developer.xero.com/documentation/api/bankfeeds/overview?utm_source=openai))
- Buildability: ready_with_caveats (self-serve app + rich API right now; scaling beyond 50 connections requires paid plan; 1,000+ connections and some APIs need certification/review; some endpoints are partner-gated). ([developer.xero.com](https://developer.xero.com/pricing))
- Blocker: app_review (for certification to reach Plus and above; some premium/partner APIs). ([developer.xero.com](https://developer.xero.com/pricing))

Notes for implementers
- Scope model is granular; offline_access needed for refresh tokens. Use Authorization Code with PKCE for multi-tenant user consent; Client Credentials is limited to non‑tenanted endpoints (e.g., managing connections). ([developer.xero.com](https://developer.xero.com/documentation/guides/oauth2/scopes/?utm_source=openai))
- Webhooks are configured per app in the developer portal. ([developer.xero.com](https://developer.xero.com/documentation/guides/webhooks/overview?utm_source=openai))
- There is also a beta Account Data API under an Advanced Developer plan gate. ([developer.xero.com](https://developer.xero.com/changelog?utm_source=openai))
