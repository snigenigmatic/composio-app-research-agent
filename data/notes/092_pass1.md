Otter.ai — research notes (Nov 24, 2026)

- Product: AI meeting assistant and transcription platform with enterprise workflow features.
- Docs URL: Otter.ai Public API help article; Otter MCP Server help article. ([help.otter.ai](https://help.otter.ai/hc/en-us/articles/36130822688279-Otter-ai-Public-API))

Auth model
- auth_methods: OAuth2 (for MCP connectors); Bearer/PAT token (Public REST API with API keys generated in-app). ([help.otter.ai](https://help.otter.ai/hc/en-us/articles/35287607569687-Otter-MCP-Server))
- primary_auth: OAuth2 (via official MCP server) for agent-style integrations; REST API uses Bearer key. ([help.otter.ai](https://help.otter.ai/hc/en-us/articles/35287607569687-Otter-MCP-Server))

Access
- self_serve_free for MCP (OAuth connect flow; no API key published); Public REST API is paid_plan, enabled for Enterprise workspaces by account manager. ([help.otter.ai](https://help.otter.ai/hc/en-us/articles/35287607569687-Otter-MCP-Server))

API surface
- Public REST API base: https://api.otter.ai/v1 (per examples). Provides endpoints to manage/read: Channels (list, members), Conversations (create via file URL, list, get details, get audio), Workspace (get, analytics). Auth with Authorization: Bearer <API_KEY>. Rate limit: 10 requests/second (Enterprise). Webhooks supported at workspace scope. ([help.otter.ai](https://help.otter.ai/hc/en-us/articles/36130822688279-Otter-ai-Public-API))
- MCP server: Hosted at https://mcp.otter.ai/mcp. Tools include get user info, search (meetings), fetch (full transcript); OAuth authorization on first connect. Guides for ChatGPT, Claude, Cursor, Perplexity. No “public API key”; support can help for custom MCP clients. ([help.otter.ai](https://help.otter.ai/hc/en-us/articles/35287607569687-Otter-MCP-Server))

MCP
- mcp: official. Otter operates an official hosted MCP server at mcp.otter.ai/mcp. ([help.otter.ai](https://help.otter.ai/hc/en-us/articles/35287607569687-Otter-MCP-Server))

Pricing/plan gating
- “Otter API & Webhooks” listed under Enterprise plan on pricing page; the status page also lists a “Public API” component. ([otter.ai](https://otter.ai/pricing?geo=US))

Breadth
- api_breadth: moderate (core objects: channels, conversations with transcript/audio/action items/insights/outline, workspace info/analytics; plus webhooks). ([help.otter.ai](https://help.otter.ai/hc/en-us/articles/36130822688279-Otter-ai-Public-API))

Buildability for Composio
- buildability: ready_with_caveats
  - Ready via MCP today (OAuth self-serve). REST API requires Enterprise enablement and uses per-user API keys. Rate limits and Enterprise gating apply. ([help.otter.ai](https://help.otter.ai/hc/en-us/articles/35287607569687-Otter-MCP-Server))
- blocker: paid_plan (for direct REST API; MCP pathway is self-serve OAuth). ([help.otter.ai](https://help.otter.ai/hc/en-us/articles/4412365535895-Does-Otter-offer-an-open-API))
