Here are the integration research notes for: NotebookLM

- Product description: Google’s “Gemini Notebook”/NotebookLM is an AI research notebook that grounds answers and media artifacts (like Audio Overviews) in your uploaded sources; the enterprise edition exposes management and limited creation APIs.

Auth model
- auth_methods: OAuth2
- primary_auth: OAuth2
  - Gemini Notebook Enterprise APIs use a Google user OAuth access token (via gcloud) and require appropriate IAM roles and an active enterprise license. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks))

Access
- access: paid_plan
  - The documented Notebook APIs are for Gemini Notebook Enterprise and require licenses; Google lists a self‑serve 30‑day trial, then $9/user/month with a 15‑license minimum. ([cloud.google.com](https://cloud.google.com/gemini-enterprise/gemini-notebook?utm_source=openai))
  - Note: A standalone “Podcast API” exists and does not require Notebook Enterprise licenses, just a Google Cloud project and IAM role; it still authenticates with OAuth2. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/podcast-api))

API surface
- api_breadth: moderate
  - Documented Enterprise APIs cover: notebooks CRUD/list/share; adding/retrieving/deleting sources (Docs, Slides, raw text, web, YouTube, file upload); and creating/deleting an Audio Overview for a notebook. There’s also a standalone Podcast API. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks))

MCP server
- mcp: community
  - Community tooling (not by Google) provides an MCP server and local REST server around the web app; not official. ([github.com](https://github.com/authorityandbrand/notebooklm/blob/main/docs/installation.md))

Buildability for Composio
- buildability: ready_with_caveats
  - Why: APIs are published with clear REST examples and an RPC reference; auth is standard Google OAuth2. Caveats: Enterprise licensing (paid), Pre‑GA/v1alpha status, and that only parts of the product surface are exposed; the personal NotebookLM has no public API. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks))

Blocker
- blocker: paid_plan

Docs URL
- Primary developer docs: Create and manage notebooks (API) — Gemini Notebook Enterprise. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks))

OpenAPI, webhooks, sandbox
- OpenAPI spec: No public OpenAPI published for NotebookLM Enterprise; Google provides REST examples and an RPC/Proto reference (OAuth scopes documented). ([docs.cloud.google.com](https://docs.cloud.google.com/generative-ai-app-builder/docs/reference/rpc/google.cloud.notebooklm.v1alpha))
- Webhooks: None documented for NotebookLM Enterprise.
- Sandbox: No separate sandbox; access is via Google Cloud projects. A 30‑day self‑serve trial for Enterprise licenses is available. ([cloud.google.com](https://cloud.google.com/gemini-enterprise/gemini-notebook?utm_source=openai))

How a developer gets credentials (summary)
- Create/choose a Google Cloud project; enable the relevant API; assign Enterprise licenses; grant IAM roles (for example, Cloud NotebookLM User); obtain a user OAuth token via gcloud (gcloud auth login; gcloud auth print-access-token) and call the v1alpha endpoints. For the standalone Podcast API, enable the Discovery Engine API and grant the Podcast API User role. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks))

Key capabilities by endpoint family (Enterprise)
- Notebooks: create, get, listRecentlyViewed, batchDelete, share. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks))
- Sources: batchCreate (Docs/Slides/web/YouTube/text), uploadFile (PDF, DOCX, PPTX, etc.), get, delete. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks-sources))
- Audio Overviews: create/delete for a notebook’s sources. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-audio-overview))
- Standalone Podcast API: generate MP3 podcast from text/images/audio/video context; does not require Notebook Enterprise license. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/podcast-api))

Notes and caveats
- Status: Many endpoints are v1alpha/Preview and under Pre‑GA terms; expect changes. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks))
- Scopes/permissions: The RPC reference documents OAuth scopes and IAM permissions for services like NotebookService, SourceService, and AudioOverviewService. ([docs.cloud.google.com](https://docs.cloud.google.com/generative-ai-app-builder/docs/reference/rpc/google.cloud.notebooklm.v1alpha))
- Personal NotebookLM: Google does not publish a consumer NotebookLM API; integrations should target the Enterprise APIs or the standalone Podcast API where applicable. ([docs.cloud.google.com](https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview?utm_source=openai))
