Lark (Larksuite) — Communications and Messaging

Product summary
- All‑in‑one workplace suite (chat, groups, calendar, docs/drive, meetings, Base/bitable) with a rich Open Platform for bots, web apps, blocks and server APIs. ([open.larksuite.com](https://open.larksuite.com/?utm_source=openai))

Auth model
- auth_methods: OAuth2; Bearer/PAT token (access_token types: tenant_access_token, app_access_token, user_access_token)
- primary_auth: OAuth2
- Notes: Public, multi‑tenant distribution uses the marketplace (store app) model with user authorization; server-to-server calls commonly use tenant_access_token scoped to a tenant. ([open.larksuite.com](https://open.larksuite.com/document/uAjLw4CM/uYjL24iN/mobile-app/mobile-app-overview?utm_source=openai))

Access and gating
- access: app_review
- Why: You can self‑serve create apps and get credentials in the Developer Console, but distributing a public app via the Lark App Directory requires ISV certification and platform review; permissions for store apps are reviewed during publishing/install. ([open.larksuite.com](https://open.larksuite.com/document/home/app-types-introduction/self-built-apps-and-store-apps?utm_source=openai))

API surface
- api_breadth: broad (IM, groups, docs, drive, sheets, Base/bitable, calendar, meetings, approvals, contacts, etc.). ([open.larksuite.com](https://open.larksuite.com/document/client-docs/intro?utm_source=openai))

Model Context Protocol (MCP)
- mcp: official
- Notes: “OpenAPI MCP Tool” maintained by Lark connects agents to core Open Platform APIs; supports tenant_access_token and user_access_token. ([open.larksuite.com](https://open.larksuite.com/document/mcp_open_tools/mcp-user-guide?utm_source=openai))

Buildability for an agent toolkit
- buildability: ready_with_caveats
- blocker: app_review
- Rationale: APIs and credentials are self‑serve and well‑documented; event webhooks and OAuth are available. Public, multi‑tenant distribution and some scopes require ISV certification/review; custom (internal) apps work immediately within a tenant. ([open.larksuite.com](https://open.larksuite.com/document/home/app-types-introduction/self-built-apps-and-store-apps?utm_source=openai))

Docs and platform details
- Docs URL: https://open.larksuite.com/
- OpenAPI spec: not publicly published/found (no Swagger/OpenAPI schema exposed; SDKs + reference docs instead).
- Webhooks: yes (Event Subscriptions/callbacks).
- Sandbox: yes (“Test Companies and Users” provides test companies/users and a test app version with immediate effect without admin approval). ([open.larksuite.com](https://open.larksuite.com/document/home/develop-a-bot-in-5-minutes/step-5-configure-event-subscription?utm_source=openai))
