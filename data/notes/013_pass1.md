Here’s what I found on Freshdesk for Composio integration research.

Product one‑liner
- Freshdesk is Freshworks’ cloud helpdesk platform for ticketing, knowledge base, automations, and omnichannel customer support. ([developers.freshdesk.com](https://developers.freshdesk.com/api/))

Auth model
- auth_methods: OAuth2; API key
- primary_auth: OAuth2 (Freshworks apps support OAuth 2.0 with scopes; the REST docs also expose OAuth scopes per endpoint.) ([developers.freshworks.com](https://developers.freshworks.com/docs/app-sdk/v3.0/support_ticket/oauth-implementation-in-apps/?utm_source=openai))
- Notes:
  - API key works by sending the key as the Basic auth username with “X” as password; sample curl uses -u apikey:X. ([developers.freshdesk.com](https://developers.freshdesk.com/api/))
  - Agents and “service accounts” can hold/managing API keys via API. ([developers.freshdesk.com](https://developers.freshdesk.com/api/))

Access and gating
- access: app_review
  - Rationale: Cross‑tenant OAuth requires publishing a Freshworks Marketplace app, which goes through a structured review before listing. Devs can self‑serve keys and build Custom/Private apps, but broad distribution/OAuth at scale requires review. ([developers.freshworks.com](https://developers.freshworks.com/docs/app-sdk/v3.0/product/app-submission-process/?utm_source=openai))
- Additional plan notes:
  - API access is plan‑based; Free plan has 0 calls/min; trials get 50 calls/min; paid Growth/Pro/Enterprise raise limits. ([support.freshdesk.com](https://support.freshdesk.com/support/solutions/articles/225439-what-are-the-rate-limits-for-the-api-calls-to-freshdesk))
  - “How to find your API key” shows availability only on paid tiers (Free disabled). ([support.freshdesk.com](https://support.freshdesk.com/support/solutions/articles/215517-how-to-find-your-api-key))

API surface
- api_breadth: broad (tickets, contacts, companies, agents, conversations, solutions/KB, email, time entries, business hours, settings, jobs, etc., with full CRUD across core objects). ([developer.freshdesk.com](https://developer.freshdesk.com/api/?utm_source=openai))
- Version/style: REST JSON, primary base path /api/v2. ([developers.freshdesk.com](https://developers.freshdesk.com/api/))

MCP (Model Context Protocol)
- mcp: official
  - Freshworks documents an official MCP server for Freshdesk, exposed per-tenant at https://<subdomain>.freshdesk.com/mcp, currently authenticated with API key only (no OAuth yet). GA since Sep 10, 2026. ([crmsupport.freshworks.com](https://crmsupport.freshworks.com/support/solutions/articles/50000014411-freshworks-mcp-security))

Buildability for Composio
- buildability: ready_with_caveats
- blocker: app_review
  - Why: We can ship immediately using API keys (trial or paid plans), but a best‑practice multi‑tenant connector using OAuth requires Marketplace app review; also rate limits vary by plan. ([support.freshdesk.com](https://support.freshdesk.com/support/solutions/articles/225439-what-are-the-rate-limits-for-the-api-calls-to-freshdesk))

Other developer details
- Docs URL: https://developers.freshdesk.com/api/ ([developers.freshdesk.com](https://developers.freshdesk.com/api/))
- OpenAPI spec: none official published (Freshworks community confirms no OpenAPI; third‑party specs exist). ([community.freshworks.dev](https://community.freshworks.dev/t/freshdesk-openapi-json-specification/6061))
- Webhooks: yes (via automation rules; outbound webhooks contribute to API rate limits). ([support.freshdesk.com](https://support.freshdesk.com/support/solutions/articles/225430-what-are-webhooks-?utm_source=openai))
- Sandbox: yes, but gated (Enterprise/selected tiers only; “Set up your sandbox account” docs indicate Enterprise for current lineup). ([support.freshdesk.com](https://support.freshdesk.com/support/solutions/articles/233591-set-up-your-sandbox-account))
- Rate limits: minute‑based per plan; Free=0/min, Trial=50/min; Growth/Pro/Enterprise increase to 100/400/700 per minute with per‑endpoint caps. ([support.freshdesk.com](https://support.freshdesk.com/support/solutions/articles/225439-what-are-the-rate-limits-for-the-api-calls-to-freshdesk))

Caveats and gotchas
- Using OAuth 2.0 across many customer accounts generally implies building a Marketplace app and passing review; otherwise you’ll need users’ API keys (service/agent) which is viable but operationally heavier. ([developers.freshworks.com](https://developers.freshworks.com/docs/app-sdk/v3.0/product/app-submission-process/?utm_source=openai))
- API access is not available on Free and is throttled by plan; trials are usable for development but limited. ([support.freshdesk.com](https://support.freshdesk.com/support/solutions/articles/225439-what-are-the-rate-limits-for-the-api-calls-to-freshdesk))
- Freshdesk’s official docs do not ship an OpenAPI schema; code‑gen/agent tools will rely on hand‑rolled specs or third parties. ([community.freshworks.dev](https://community.freshworks.dev/t/freshdesk-openapi-json-specification/6061))
- Freshdesk MCP exists and is officially supported, but today authenticates via API key only (no OAuth). ([crmsupport.freshworks.com](https://crmsupport.freshworks.com/support/solutions/articles/50000014411-freshworks-mcp-security))
