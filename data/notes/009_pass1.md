Here’s what I found on Copper (CRM) from primary sources.

Research notes
- Product: Copper — CRM built for Google Workspace teams; offers a public “Developer API” for CRM objects and webhooks. 
- Docs URL: https://developer.copper.com/ (Developer API portal). ([developer.copper.com](https://www.developer.copper.com/?utm_source=openai))
- API surface (summary): REST JSON covering Accounts/Users, Leads, People, Companies, Opportunities, Projects, Tasks, Activities, Custom Fields/Definitions, Tags, Related Items, File Uploads, Webhooks, Field Layouts, Connect fields, Search and pagination. API rate limit documented as 180 requests/min. ([developer.copper.com](https://www.developer.copper.com/introduction/authentication.html))
- auth_methods: OAuth2; API key. ([developer.copper.com](https://www.developer.copper.com/introduction/authentication.html))
- primary_auth: OAuth2 (preferred for partner/multi-tenant integrations; requires prior app registration). API keys remain available per-admin for single-tenant tooling. ([developer.copper.com](https://www.developer.copper.com/introduction/oauth/index.html))
- access: paid_plan (Developer API is included on trial, Professional and Business; not on Basic). Trial gives time‑limited access. ([support.copper.com](https://support.copper.com/en/articles/8823462-api-docs-and-tips?utm_source=openai))
- api_breadth: broad (dozens of resources incl. CRUD plus webhooks, search, bulk ops, file upload). ([developer.copper.com](https://www.developer.copper.com/introduction/authentication.html))
- mcp: official (announced by Copper; beta “coming soon” to Claude, launching November 2026). ([copper.com](https://www.copper.com/mcp?utm_source=openai))
- buildability: ready_with_caveats
  - Rationale: API keys are self-serve for admins once the account has API access (Pro/Business or trial); OAuth2 (best for multi-tenant) requires partner registration; plan gating and 180 rpm limits apply. ([support.copper.com](https://support.copper.com/en/articles/8823347-generating-an-api-key?utm_source=openai))
- blocker: paid_plan (Pro/Business for ongoing API use; OAuth client registration also requires contacting partners@copper.com). ([support.copper.com](https://support.copper.com/en/articles/9623758-copper-plans-feature-comparison))
- OpenAPI spec: Yes — Copper publishes an OpenAPI 3.1 document at https://developer.copper.com/v1/openapi.json (used in their “Custom Copper GPT” guide). ([support.copper.com](https://support.copper.com/en/articles/13004601-how-to-create-a-custom-copper-gpt))
- Webhooks: Yes — create/list/update/delete subscriptions; entity create/update/delete events; up to 100 subscriptions; no retries; HTTPS only. ([developer.copper.com](https://www.developer.copper.com/webhooks/overview.html))
- Sandbox: Not documented as a separate environment/host in official docs; teams typically use the 14‑day trial or a non‑production workspace for testing. (Couldn’t find an official “sandbox” mention beyond general trial guidance.) ([support.copper.com](https://support.copper.com/en/articles/8823462-api-docs-and-tips?utm_source=openai))

What this means for a Composio toolkit
- Auth to implement: 
  - Preferred: OAuth2 Authorization Code (requires app registration via partners@copper.com to obtain client_id/secret). 
  - Fallback: API key flow with headers X-PW-AccessToken, X-PW-UserEmail, X-PW-Application=developer_api. ([developer.copper.com](https://www.developer.copper.com/introduction/oauth/index.html))
- Plan gating: Only Professional/Business (and trial) accounts expose the API, so production users on Basic will not be able to connect. ([support.copper.com](https://support.copper.com/en/articles/8823462-api-docs-and-tips?utm_source=openai))
- Scope and limits: One coarse scope for OAuth today (developer/v1/all); REST rate limit 180 rpm; bulk endpoints 3 rps. Design calls with backoff + pagination. ([developer.copper.com](https://www.developer.copper.com/introduction/oauth/index.html))
