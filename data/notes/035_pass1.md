Here are the integration research notes for: Mailchimp

- Product description: Mailchimp is an email and marketing automation platform; its Marketing API lets apps manage audiences, campaigns, automations and more on behalf of users. ([mailchimp.com](https://mailchimp.com/developer/marketing?utm_source=openai))
- Docs URL: https://mailchimp.com/developer/ ([mailchimp.com](https://mailchimp.com/developer/?msockid=3f345abdada0692613014ccaac76680a&utm_source=openai))

Auth
- auth_methods: OAuth2; API key. Mailchimp supports OAuth 2.0 for multi-tenant integrations and API keys for first‑party or single‑account use. ([mailchimp.com](https://mailchimp.com/developer/marketing/build/start-developing/set-up-an-oauth-app))
- primary_auth: OAuth2 (recommended for connecting other users’ Mailchimp accounts). ([mailchimp.com](https://mailchimp.com/developer/marketing/build/start-developing/set-up-an-oauth-app))

Access and gating
- access: self_serve_free (create an account, generate an API key, and/or register an OAuth app without review). ([mailchimp.com](https://mailchimp.com/developer/marketing/build/get-started/generate-your-api-key))
- Notes on gating: Some capabilities vary by Mailchimp plan; docs state “what you can do with the API depends on what level of Mailchimp plan you have.” Marketplace listing and partner benefits are via a separate Integration Partner Program but not required for API credentials. ([mailchimp.com](https://mailchimp.com/developer/marketing/build/get-started/create-an-account?utm_source=openai))

API surface
- api_breadth: broad (audiences/contacts, campaigns, reports, automations, e‑commerce, webhooks, batch, etc.). ([mailchimp.com](https://mailchimp.com/developer/marketing?utm_source=openai))
- OpenAPI spec: Yes (OpenAPI 3.1 JSON/YAML linked from the docs’ llms.txt). ([mailchimp.com](https://mailchimp.com/developer/marketing/build/ai-tools/llms-txt))
- Webhooks: Yes (list/audience webhooks can be configured in app UI or via API). ([mailchimp.com](https://mailchimp.com/developer/marketing/api-concepts/webhooks?utm_source=openai))
- Sandbox: No dedicated sandbox; develop against your own account (free/trial possible). Mailchimp Transactional offers a demo with up to 500 free emails to a verified domain for new users. ([mailchimp.com](https://mailchimp.com/developer/marketing/build/start-developing/send-your-first-api-request?msockid=26124148d3976f2d1cd7573fd2696e7e&utm_source=openai))

MCP (Model Context Protocol)
- mcp: official
  - Marketing docs MCP server (docs search/QA only; no account access): https://mailchimp.com/developer/_mcp/server. ([mailchimp.com](https://mailchimp.com/developer/marketing/build/ai-tools/mcp-server/))
  - Transactional Messaging MCP server (acts on account via API key): https://mandrillapp.com/mcp. ([mailchimp.com](https://mailchimp.com/developer/transactional/guides/how-to-use-mailchimps-transactional-messaging-mcp/))

Buildability for an agent toolkit (Composio)
- buildability: ready (self‑serve credentials; extensive, well-documented API; official OpenAPI; webhooks). Caveats: Certain endpoints/features require paid plans; avoid using API keys in client-side code. ([mailchimp.com](https://mailchimp.com/developer/marketing/build/get-started/create-an-account?utm_source=openai))
- blocker: none

Research evidence (2–5 items)
- auth | https://mailchimp.com/developer/marketing/api-concepts/authentication/ | “You can start development against your own account with a key and move to OAuth 2 later; the request‑signing mechanics below are identical for both.” ([mailchimp.com](https://mailchimp.com/developer/marketing/api-concepts/authentication/?utm_source=openai))
- oauth_creds | https://mailchimp.com/developer/marketing/build/start-developing/set-up-an-oauth-app | “Registering gives you the client_id and client_secret your server needs.” ([mailchimp.com](https://mailchimp.com/developer/marketing/build/start-developing/set-up-an-oauth-app))
- api_keys | https://mailchimp.com/developer/marketing/build/get-started/generate-your-api-key | “Note: An API key grants full access to your account.” ([mailchimp.com](https://mailchimp.com/developer/marketing/build/get-started/generate-your-api-key))
- webhooks | https://mailchimp.com/developer/marketing/api-concepts/webhooks | “There are two ways to set up our webhook: in the Mailchimp web app, or through the API.” ([mailchimp.com](https://mailchimp.com/developer/marketing/api-concepts/webhooks?utm_source=openai))
- mcp_server_transactional | https://mailchimp.com/developer/transactional/guides/how-to-use-mailchimps-transactional-messaging-mcp/ | “The MCP server URL is https://mandrillapp.com/mcp.” ([mailchimp.com](https://mailchimp.com/developer/transactional/guides/how-to-use-mailchimps-transactional-messaging-mcp/))

Additional implementation notes
- OAuth2 flow uses authorize at login.mailchimp.com/oauth2/authorize and token exchange at login.mailchimp.com/oauth2/token; client_id/secret obtained from the “Registered Apps” page. ([mailchimp.com](https://mailchimp.com/developer/marketing/build/start-developing/set-up-an-oauth-app))
- API base URL: https://api.mailchimp.com/3.0/. ([mailchimp.com](https://mailchimp.com/developer/marketing/api-concepts/api-structure?utm_source=openai))
- Partner/Marketplace: You can publish integrations without Mailchimp reviewing all registered apps; Marketplace listing and partner benefits are curated via the Integration Partner Program. ([mailchimp.com](https://mailchimp.com/help/about-authorized-applications/?utm_source=openai))
