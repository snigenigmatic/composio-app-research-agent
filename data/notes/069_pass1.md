Datadog — research notes for Composio

Product: Cloud-based observability and security platform for metrics, logs, traces, monitors, Synthetics, security signals, and more.

Auth model
- auth_methods: API key; Bearer/PAT token; OAuth2
- primary_auth: Bearer/PAT token
  - Rationale: Datadog now supports Personal Access Tokens (PATs) and Service Access Tokens (SATs) that authenticate API calls without pairing an API key; OAuth2 exists but is partner-gated. ([docs.datadoghq.com](https://docs.datadoghq.com/account_management/personal-access-tokens/?utm_source=openai))

Access (how a developer gets credentials)
- access: self_serve_free
  - Notes: Self-serve 14‑day trial and then a Free tier; Datadog highlights a “full‑featured API” for sending metrics. You can create API/app keys or PAT/SAT in any org. ([datadoghq.com](https://www.datadoghq.com/free-datadog-trial/?utm_source=openai))

API surface area
- api_breadth: broad
  - Evidence: “Use the Datadog HTTP API to … send data … build data visualizations, and manage your account,” with endpoints across Metrics, Events, Dashboards, Monitors, Logs, Synthetics, Users/Roles, Usage, etc. ([docs.datadoghq.com](https://docs.datadoghq.com/api/latest/using-the-api.md))

Model Context Protocol (MCP)
- mcp: official
  - Datadog publishes “Set Up the Datadog MCP Server,” supporting OAuth or header-based PAT/SAT and app+API key auth. ([docs.datadoghq.com](https://docs.datadoghq.com/mcp_server/setup/?utm_source=openai))

Buildability for an agent toolkit
- buildability: ready_with_caveats
  - Why: You can build today using PAT/SAT (or API+application keys) that users paste/provision themselves; breadth is ample. Caveats: OAuth2 for multi-tenant consented access is only for approved Technology Partners; rate limits apply; region-specific base URLs must be handled. ([docs.datadoghq.com](https://docs.datadoghq.com/account_management/personal-access-tokens/?utm_source=openai))
- blocker: partner_program
  - If you want Datadog-hosted OAuth2 flows to authorize on customers’ orgs, you must join the Technology Partner Program and implement OAuth 2.0 for Partners. ([partners.datadoghq.com](https://partners.datadoghq.com/resource/1765384088000/PRM_TechnologyPartners))

Docs URL
- https://docs.datadoghq.com/api/latest/ ([docs.datadoghq.com](https://docs.datadoghq.com/api/latest/?utm_source=openai))

OpenAPI spec
- Yes. Datadog’s official Postman collection is “regenerated from the OpenAPI specs that power the Datadog API documentation,” and Datadog API client repos reference OpenAPI-based generation. ([postman.com](https://www.postman.com/datadog/datadog-s-public-workspace/overview?utm_source=openai))

Webhooks
- Yes (outgoing). “Webhooks Integration” exists and can be created/managed via API. ([docs.datadoghq.com](https://docs.datadoghq.com/integrations/webhooks/?utm_source=openai))

Sandbox
- Partner sandbox: The Technology Partner Program offers “access to a Datadog sandbox for development and testing.” Otherwise, use a self-serve trial org. ([partners.datadoghq.com](https://partners.datadoghq.com/resource/1765384088000/PRM_TechnologyPartners))

Key implementation notes and caveats
- Auth choices
  - PAT: single scoped bearer credential; “do not need to be paired with an API key.” Good for user-authorized agent actions. ([docs.datadoghq.com](https://docs.datadoghq.com/account_management/personal-access-tokens/?utm_source=openai))
  - SAT: service-account–scoped bearer credential; recommended for automation; can be sent as Authorization: Bearer. ([docs.datadoghq.com](https://docs.datadoghq.com/account_management/service-access-tokens/?utm_source=openai))
  - Legacy headers: Many examples still use DD-API-KEY + DD-APPLICATION-KEY; supported across regions. ([docs.datadoghq.com](https://docs.datadoghq.com/api/latest/authentication.md))
- Region base URLs
  - Datadog operates multiple sites (US1, US3, US5, EU, AP1, AP2, UK1, Gov). Select the correct api.{site} host. ([docs.datadoghq.com](https://docs.datadoghq.com/api/latest/authentication.md))
- Rate limits
  - Global guidance plus endpoint-specific limits (e.g., spans analytics aggregate = 50 rpm per org). Build backoff/retry. ([docs.datadoghq.com](https://docs.datadoghq.com/api/latest/rate-limits/?utm_source=openai))
