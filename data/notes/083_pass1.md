Here are the integration research notes for Binance.

- Product: Binance
- One‑line description: Global crypto exchange and developer platform with REST, WebSocket, FIX/SBE, and agent-native (MCP) interfaces for market data, trading, wallets, and related services.
- Docs URL: https://developers.binance.com/en/docs/introduction
- Auth methods: HMAC/signature; also supports RSA and Ed25519 signature keys; partner-gated OAuth2 (Binance Login) exists
- Primary auth: HMAC/signature
- Access: self_serve_free (create API keys in your account; KYC/account activation required)
- API breadth: broad
- MCP: official (Binance MCP Server)
- Buildability: ready_with_caveats
- Blocker: none
- OpenAPI spec: no official OpenAPI/OAS published; endpoint refs and SDKs provided
- Webhooks: not for Spot/Futures; yes for Binance Pay Merchant (payments) webhooks
- Sandbox: yes — Spot Testnet and Futures Demo/Testnet

Key caveats for an agent toolkit
- Regional eligibility and product enablement vary (e.g., some features not available in the U.S.).
- API keys require security controls; trading/withdrawal permissions often gated by IP allowlists and key type; users must complete KYC and sometimes make an initial deposit before key creation.
- Multiple API “families” (Spot, USDⓈ‑M/COIN‑M Futures, Margin, Wallet, Earn, Link/VIP, Pay) have different bases, limits, and permission scopes.
- MCP Server authorizes against an Agentic sub‑account and omits withdrawal scope.

Notes for Composio
- The default multi‑tenant flow should use user‑supplied API Key + signature (primary_auth). Binance OAuth2 is partner‑gated and not suitable as a general primary auth, though it exists.
- Prefer Spot/Futures official docs under “API Reference” and product‑specific sections for limits/filters; Spot supports REST, WS API, WS Streams, FIX, SBE. ([developers.binance.com](https://developers.binance.com/en/docs/catalog))
- MCP route: Binance operates an official MCP server that authorizes via web flow to an Agentic sub‑account and supports read/act scopes (no withdrawals). This can power an agent-native tool without handling raw API keys. ([binance.com](https://www.binance.com/en/support/faq/detail/7a6e676e36fb455d96478932cb12d9f3))
