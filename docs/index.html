Run it yourself

Source, prompts, per-app raw notes and every intermediate JSON: 

git clone  && cd composio-app-research-agent
pip install -r requirements.txt
cp .env.example .env            # OPENAI_API_KEY (or ANTHROPIC_API_KEY) + COMPOSIO_API_KEY
python -m agent.pipeline all --only 81,15,84   # research → oracles → skeptic → adjudicate, 3 apps
python -m agent.analyze && python site/build.py   # results.json + this page

For agents: results.json has every record with enums, evidence and the verification trail. results.csv is the flat version.
